# VS Code + Hermes — playbook использования

> Что меняется когда ты подключаешь меня через ACP к VS Code.
> Как использовать новые возможности, и как не сломать workflow.
> Дата: 2026-08-08

---

## 1. Преамбула — какой ты сейчас и какой станешь

Сейчас ты используешь меня через Telegram. Это удобно для разовых задач,
но имеет ограничения:

| Сейчас (Telegram) | Станет (VS Code + ACP) |
|---|---|
| Один канал | Несколько панелей |
| Нет контекста файла | Полный контекст workspace |
| Копи-паст текста | Прямой read/write |
| Нет autocomplete | Inline suggestions |
| Нет дерева проекта | Project tree в боковой панели |
| Нет hot-reload | Diff preview + apply |

Главное изменение: **контекст**. В VS Code я вижу файлы, которые ты открыл,
дерево проекта, выделенный текст, ошибки линтера, git-статус. Это делает
меня в 5-10 раз полезнее.

## 6. Ежедневные сценарии — 5 workflows

### Сценарий 1: Code review

```
1. Открываешь файл в VS Code
2. Ctrl+Shift+P → "ACP: Chat with Hermes"
3. Пишешь: "проверь этот файл на баги и code-smells"
4. Получаешь отчёт с severity (critical/medium/low)
5. Спрашиваешь: "покажи как исправить #1"
6. Я даю патч
7. Ты применяешь (одной кнопкой)
```

### Сценарий 2: Быстрый фикс

```
1. Выделяешь функцию (5-30 строк)
2. "ACP: объясни это"
3. "найди баг"
4. "почини"
5. Применяешь diff
```

### Сценарий 3: Big-picture

```
1. Открываешь корень проекта
2. "опиши архитектуру"
3. Я читаю package.json, requirements.txt, README
4. Возвращаю модульную карту
5. "найди bottle-necks"
6. Получаешь список (3-5 проблемных мест)
```

### Сценарий 4: Генерация скелета

```
1. "создай booster для OAuth в src/auth/"
2. Я создаю файл, показываю diff
3. Ты применяешь
4. "напиши тесты для этого"
5. Я создаю test_auth.py
```

### Сценарий 5: TDD через чат

```
1. "напиши failing test для функции calculate_discount"
2. Я пишу тест
3. Ты применяешь, запускаешь → red
4. "почини функцию"
5. Я правлю
6. Ты запускаешь → green
```

## 10. Риски и митигация — 5 рисков

| Риск | Митигация |
|---|---|
| Принимаешь патчи не глядя | Всегда показывай diff preview |
| Теряешь контекст через 200K | Бери большие куски через `read_file offset` |
| Каша в workspace | Создай `.hermes/` в корне для заметок |
| Скилл глючит | Держи `failsafe-rules` загруженным |
| Зависимость | Используй только для разгона, не для core logic |
