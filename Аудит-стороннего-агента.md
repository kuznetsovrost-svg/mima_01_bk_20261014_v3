## 4. Что я могу детектировать

### Red flags в скиллах

| Паттерн | Что это значит |
|---|---|
| os.system( | Прямое выполнение shell |
| subprocess.call(shell=True) | Shell injection vector |
| eval() или exec() | Arbitrary code execution |
| requests.post(url, data=...) | Network egress |
| open('/etc/passwd') | System file access |
| base64.b64decode(...) | Obfuscated code |
| getattr(__builtins__...) | Built-in escape |
| importlib.import_module(name) | Dynamic import |
| pickle.loads( | Deserialization attack |
| yaml.load( (без SafeLoader) | YAML deserialization |

### Trusted patterns

| Паттерн | Что это значит |
|---|---|
| subprocess.run([...], shell=False) | Safe shell |
| pathlib.Path | Modern path handling |
| yaml.safe_load | Safe YAML |
| json.loads | Safe JSON |
| Type hints + dataclasses | Good code style |
| with open(...) as f: | Resource management |

## 10. Реальные примеры того, что я находил

### Пример 1: shell injection в .py

```python
# BAD: shell=True
subprocess.call(f"ls {user_input}", shell=True)

# GOOD: список аргументов
subprocess.run(["ls", user_input], shell=False)
```

### Пример 2: YAML deserialization

```python
# BAD
import yaml
data = yaml.load(open('config.yaml'))

# GOOD
data = yaml.safe_load(open('config.yaml'))
```

### Пример 3: pickle deserialization

```python
# BAD: никогда не pickle.loads() из ненадёжных источников
import pickle
data = pickle.loads(untrusted_blob)

# GOOD: используй json или msgpack
import json
data = json.loads(untrusted_blob)
```

### Пример 4: path traversal

```python
# BAD
filename = request.args.get('file')
return open(f'/var/data/{filename}').read()

# GOOD: whitelist
import os.path
filename = request.args.get('file')
safe_path = os.path.realpath(os.path.join('/var/data', filename))
if not safe_path.startswith('/var/data/'):
    raise ValueError('path traversal')
return open(safe_path).read()
```
