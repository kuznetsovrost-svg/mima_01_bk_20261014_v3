# Подсветка строк в таблице (Figma → HTML шаблон)

## Суть проблемы

В Figma-компоненте `cmp.collapsible-row` (вариант `state=expanded`) внутри `body` лежит таблица замечаний. Каждая строка — это запись о контрольной точке проекта. Нужно, чтобы **при заполнении шаблона данными** (уже после экспорта в HTML) строка получила нужный фон:
- 🔴 красный — критическое замечание
- 🟡 жёлтый — существенное замечание
- ⚪ без подсветки — обычное замечание

В design-time Figma нельзя заранее знать, какие строки будут критическими.

## Главное правило

**В Figma-дизайне НЕ РАСКРАШИВАЕМ строки.** Дизайн — нейтральный. Цвет появляется только в HTML-шаблоне через **условный CSS-класс** на элементе `<tr>`. Это даёт:
- Один макет для всех проектов (где 0, 1, 2, 3+ критических замечаний)
- Простое обновление палитры (один CSS-файл меняет ВСЕ проекты)
- Поддержку тёмной темы автоматически
- Соответствие дизайн-токенам (`Status/Critical/Bg`, `Status/Attention/Bg`)

## Что рисуем в Figma

### 1. Строка-шаблон `tr.template` — нейтральная

```
Frame "tr.template" (Auto Layout horizontal, gap: 0, padding: 0×12)
  ├── auto-layout: HORIZONTAL, gap: 0, padding: 12 (vertical) × 12 (horizontal)
  ├── width: Fill container (100%)
  ├── height: AUTO (растягивается по контенту)
  ├── fill: Background/Card (#FFFFFF)              ← нейтральный
  ├── stroke: Border/Default 1px, only bottom       ← граница снизу
  ├── corner radius: 0
  └── children:
      ├── Frame "td.status" (62px, fill: пусто)       ← бейдж статуса
      ├── Frame "td.code" (90px, fill: пусто)         ← "104-721"
      ├── Frame "td.name" (260px, fill: пусто)        ← "Замечание #..."
      ├── Frame "td.plan" (110px, fill: пусто)        ← "2026-06-01"
      ├── Frame "td.forecast" (120px, fill: пусто)    ← "2026-06-13"
      ├── Frame "td.fact" (100px, fill: пусто)        ← "—" или "2026-06-15"
      └── Frame "td.executor" (220px, fill: пусто)    ← "Кузнецов Р.В. (120872)"
```

**Ключевое:** `fill` НЕ задан (или `Background/Card`). Никакого цвета фона.

### 2. Внутри `td.status` — плейсхолдер для бейджа

```
Frame "td.status" (62px × 32px, fill: пусто)
  └── Component Instance "badge"
        └── Variant: state=neutral (default в дизайне)
```

Badge как **отдельный Component** с Variants (см. Динамические-цвета-в-FIGMA.md):
- `state=critical` 🔴
- `state=attention` 🟡
- `state=healthy` 🟢
- `state=neutral` ⚪ (default — используем в дизайне)

### 3. Внутри `td.executor` — текст с плейсхолдером

```
Text "txt.executor"
  content: {row.executor}
  Style: Body/Default (16px)
  Color: Text/Body (#4B5563)
```

## Что НЕ рисуем в Figma (но делаем в плагине при экспорте)

### 1. CSS-классы на `<tr>` через условный шаблон

В HTML-шаблоне строка получит один из классов:

```html
<tr class="row">                                ← обычная
<tr class="row row--critical">                  ← 🔴 критическое
<tr class="row row--attention">                 ← 🟡 существенное
```

### 2. CSS-стили для подсветки

```css
.row {
  background: var(--bg-card);
  border-bottom: 1px solid var(--border-muted);
}

.row--critical {
  background: var(--status-critical-bg);     /* #FEE2E2 */
  border-bottom-color: var(--status-critical-border);
}

.row--critical .td.status {
  background: var(--status-critical-bg-hover);  /* чуть темнее */
}

.row--attention {
  background: var(--status-attention-bg);    /* #FEF3C7 */
  border-bottom-color: var(--status-attention-border);
}

.row--attention .td.status {
  background: var(--status-attention-bg-hover);
}
```

**Все цвета — токены** (`Status/Critical/Bg`, `Status/Attention/Bg`). При смене темы (light → dark) подсветка меняется автоматически.

## 3 варианта реализации в шаблоне

### Вариант A — Jinja2 (самый простой, рекомендуемый)

```html
<tbody>
  {% for row in remarks %}
  <tr class="row {% if row.severity == 'critical' %}row--critical{% elif row.severity == 'attention' %}row--attention{% endif %}">
    <td class="td td--status">
      <span class="badge badge--{{ row.severity }}">
        {{ row.severity_label }}
      </span>
    </td>
    <td class="td td--code">{{ row.code }}</td>
    <td class="td td--name">{{ row.name }}</td>
    <td class="td td--plan">{{ row.plan_date }}</td>
    <td class="td td--forecast">{{ row.forecast_date }}</td>
    <td class="td td--fact">{{ row.fact_date or '—' }}</td>
    <td class="td td--executor">{{ row.executor }}</td>
  </tr>
  {% endfor %}
</tbody>
```

**Преимущество:** условная логика прямо в шаблоне, читается естественно.

### Вариант B — JavaScript на клиенте (если данные приходят через API)

```javascript
const rows = document.querySelectorAll('.row');
rows.forEach(row => {
  const severity = row.dataset.severity;  // "critical" / "attention" / "neutral"
  if (severity && severity !== 'neutral') {
    row.classList.add(`row--${severity}`);
  }
});
```

**HTML:**
```html
<tr class="row" data-severity="{{ row.severity }}">
```

**Преимущество:** данные могут подгружаться динамически.

### Вариант C — CSS-атрибут (без JS, без Jinja)

```css
.row[data-severity="critical"] {
  background: var(--status-critical-bg);
}

.row[data-severity="attention"] {
  background: var(--status-attention-bg);
}
```

```html
<tr class="row" data-severity="critical">
  <td class="td td--status">...</td>
  ...
</tr>
```

**Преимущество:** работает даже без шаблонизатора. CSS один раз описывает все стили.

**Рекомендую:** Вариант A (Jinja2) для серверной генерации, Вариант C для статических HTML-файлов.

## Полная структура компонента (с учётом подсветки)

```
📦 cmp.collapsible-row (Component)
├── variant=collapsed (default)
│   └── row [horizontal: chevron + title]
│       └── text: "{rows.length} записей"
│
└── variant=expanded
    └── row [vertical]
        ├── header [horizontal: chevron-down + title, bottom border]
        └── body [vertical, padding: 0]
            └── tbl.remarks (Component Instance)
                ├── thead [horizontal: th.status / th.code / th.name / th.plan / th.forecast / th.fact / th.executor]
                └── tbody [vertical: tr.template]
                    └── tr.template [horizontal: td.status / td.code / td.name / td.plan / td.forecast / td.fact / td.executor]
                        ├── td.status (62px) [vertical center, padding: 8 horizontal]
                        │   └── badge (Component Instance, variant=neutral)
                        ├── td.code (90px)
                        │   └── text: "{row.code}"  (Body/Default)
                        ├── td.name (260px)
                        │   └── text: "{row.name}"  (Body/Default)
                        ├── td.plan (110px)
                        │   └── text: "{row.plan_date}"  (Body/Default)
                        ├── td.forecast (120px)
                        │   └── text: "{row.forecast_date}"  (Body/Default)
                        ├── td.fact (100px)
                        │   └── text: "{row.fact_date or '—'}"  (Body/Default)
                        └── td.executor (220px)
                            └── text: "{row.executor}"  (Body/Default)
```

**Важно:** `tr.template` — **одна строка-образец**, без цвета фона. В коде это станет `{% for row in remarks %} ... {% endfor %}`.

## Как Figma-плагин "HTML+CSS" это экспортирует

Плагин смотрит на структуру Auto Layout и выдаёт:

```html
<table class="tbl-remarks">
  <thead>
    <tr>
      <th class="th th--status">...</th>
      <th class="th th--code">Код</th>
      <th class="th th--name">Название</th>
      <th class="th th--plan">План</th>
      <th class="th th--forecast">Прогноз</th>
      <th class="th th--fact">Факт</th>
      <th class="th th--executor">Исполнитель</th>
    </tr>
  </thead>
  <tbody>
    <tr class="row">
      <td class="td td--status">
        <span class="badge badge--neutral">...</span>
      </td>
      <td class="td td--code">{row.code}</td>
      <td class="td td--name">{row.name}</td>
      ...
    </tr>
  </tbody>
</table>
```

**Дальше я (Hermes) сделаю:**
1. Заменю `{row.code}` → `{{ row.code }}` (Jinja2)
2. Добавлю условие `{% if row.severity == 'critical' %}row--critical{% endif %}` на `<tr class="row">`
3. Положу CSS (см. ниже) в `<style>` или внешний файл

## CSS с переменными (для светлой и тёмной темы)

```css
/* Токены импортируются из figma-tokens-full.json */

  background: var(--bg-card);
  border-bottom: 1px solid var(--border-muted);
  transition: background 0.2s ease;

.row:hover {
  background: var(--bg-subtle);

.row--critical {
  background: var(--status-critical-bg);
  border-bottom-color: var(--status-critical-border);

  background: var(--status-critical-bg-hover);

  background: var(--status-attention-bg);
  border-bottom-color: var(--status-attention-border);

.row--attention:hover {
  background: var(--status-attention-bg-hover);

/* Бейдж внутри td.status */
.td--status .badge {
  display: inline-flex;

  border-radius: var(--radius-pill);

  color: var(--status-attention-text);

  background: var(--bg-subtle);
  color: var(--text-muted);
}
```

## Чек-лист для Figma

- [ ] Создать отдельный Component `badge` с Variants `state=critical|attention|healthy|neutral`
- [ ] В `tr.template` оставить `fill` пустым (нейтральный фон)
- [ ] Все `td.*` — нейтральный фон, без подсветки
- [ ] Text-слои содержат плейсхолдеры `{row.code}`, `{row.name}` и т.д.
- [ ] В `td.status` положить **Instance** компонента `badge` (default — neutral)
- [ ] Не использовать `data-severity` атрибут в Figma — добавится в HTML при экспорте
- [ ] Цвет границы (`stroke`) — `Border/Default`, не красный/жёлтый
- [ ] Auto Layout: `tr.template` horizontal, `tbody` vertical, `tbl` vertical
- [ ] Width всех ячеек = Fixed (для таблицы важна фиксированная ширина колонок)

## Преимущества этого подхода

| Плюс | Пояснение |
|---|---|
| **Один макет на все случаи** | 0, 1, 5, 20 критических замечаний — тот же HTML |
| **Палитра меняется в одном месте** | Поменял токен `Status/Critical/Bg` → обновилось везде |
| **Тёмная тема бесплатно** | Все цвета через CSS-переменные |
| **Экспорт чистый** | Figma не знает про severity, экспортирует нейтральную таблицу |
| **A11y работает** | `<tr>` с классом — скринридер читает "строка 1, критическое, код 104-721" |
| **Hover и focus** | Легко добавить `:hover` или `:focus` на `.row--critical` |
| **Печать** | `print { .row--critical { background: #fde2e2; } }` — работает |

## Итоговая шпаргалка

> В Figma строка **нейтральная**, цвет фона `Background/Card`. В HTML `<tr class="row {% if row.severity == 'critical' %}row--critical{% endif %}">`. CSS через CSS-переменные `var(--status-critical-bg)`. Один макет на все комбинации severity.
