# СИНТАКСИС ОТПРАВКИ ФАЙЛА В TELEGRAM

## Готовая команда (использую сам)

```bash
TOK=$(grep '^TELEGRAM_BOT_TOKEN=' /root/.hermes/.env | cut -d= -f2- | tr -d '\n') && \
curl -sS \
     -F document=@"/root/ИМЯ-ФАЙЛА.md" \
     -F chat_id=505586502 \
     -F caption="ПОДПИСЬ К ФАЙЛУ" \
     "https://api.telegram.org/bot${TOK}/sendDocument"
```

## Расшифровка по частям

| Часть | Назначение |
|---|---|
| `TOK=$(grep ...)` | Извлечь токен из `/root/.hermes/.env` |
| `cut -d= -f2-` | Взять всё после `=` |
| `tr -d '\n'` | Убрать перевод строки |
| `curl -sS` | Тихий, но с ошибками |
| `-F document=@"/root/файл"` | Файл с диска (multipart form) |
| `-F chat_id=505586502` | Твой chat_id |
| `-F caption="..."` | Подпись (опционально, до 1024 символов) |
| `"https://api.telegram.org/bot${TOK}/sendDocument"` | Endpoint |

## Варианты использования

### Просто отправить (без подписи)
```bash
TOK=$(grep '^TELEGRAM_BOT_TOKEN=' /root/.hermes/.env | cut -d= -f2- | tr -d '\n') && \
curl -sS -F document=@"/root/файл.md" -F chat_id=505586502 \
     "https://api.telegram.org/bot${TOK}/sendDocument"
```

### Отправить и сохранить ответ
```bash
TOK=$(grep '^TELEGRAM_BOT_TOKEN=' /root/.hermes/.env | cut -d= -f2- | tr -d '\n') && \
curl -sS -F document=@"/root/файл.md" -F chat_id=505586502 \
     -F caption="Подпись" \
     "https://api.telegram.org/bot${TOK}/sendDocument" \
     -o /tmp/tg_resp.json
```

### Проверить ответ
```bash
python3 -c "import json; d=json.load(open('/tmp/tg_resp.json')); print('OK' if d.get('ok') else 'FAIL'); print(json.dumps({'message_id': d['result']['message_id'], 'file_name': d['result']['document']['file_name'], 'file_size': d['result']['document']['file_size']}, ensure_ascii=False, indent=2))"
```

### Кириллица в имени файла
```bash
cp "/tmp/Файл-с-кириллицей.md" "/root/Файл-с-кириллицей.md" && \
TOK=$(grep '^TELEGRAM_BOT_TOKEN=' /root/.hermes/.env | cut -d= -f2- | tr -d '\n') && \
curl -sS -F document=@"/root/Файл-с-кириллицей.md" -F chat_id=505586502 \
     "https://api.telegram.org/bot${TOK}/sendDocument"
```

## Что я обычно делаю (полная цепочка)

```bash
# 1. Записать файл в /tmp/ (защита от инъекций)
write_file_safe /tmp/ИМЯ-ФАЙЛА.md "содержание"

# 2. Проверить безопасность
python3 -c "d=open('/tmp/ИМЯ-ФАЙЛА.md','rb').read(); bad=[(i,hex(b)) for i,b in enumerate(d) if b<0x20 and b not in (9,10,13)]; print('Bad bytes:', len(bad))"

# 3. Скопировать в /root/
cp "/tmp/ИМЯ-ФАЙЛА.md" "/root/ИМЯ-ФАЙЛА.md"

# 4. Проверить SHA256
sha256sum "/tmp/ИМЯ-ФАЙЛА.md" "/root/ИМЯ-ФАЙЛА.md"

# 5. Отправить
TOK=$(grep '^TELEGRAM_BOT_TOKEN=' /root/.hermes/.env | cut -d= -f2- | tr -d '\n') && \
curl -sS -F document=@"/root/ИМЯ-ФАЙЛА.md" \
     -F chat_id=505586502 \
     -F caption="ОПИСАНИЕ" \
     "https://api.telegram.org/bot${TOK}/sendDocument" \
     -o /tmp/tg_resp.json

# 6. Проверить ответ
python3 -c "import json; d=json.load(open('/tmp/tg_resp.json')); print('OK' if d.get('ok') else 'FAIL'); print(json.dumps({'message_id': d['result']['message_id'], 'file_name': d['result']['document']['file_name'], 'file_size': d['result']['document']['file_size']}, ensure_ascii=False, indent=2))"
```

## Лимиты

| Параметр | Лимит |
|---|---|
| Размер файла | 50 MB |
| Caption | 1024 символа |
| Частота | 1 msg/sec на чат |

## Ошибки и решения

| Ошибка | Решение |
|---|---|
| `chat not found` | Написать боту `/start` |
| `Unauthorized` | Токен протух → переполучить у @BotFather |
| `Forbidden: bot was blocked` | Разблокировать в Telegram |
| `Too Many Requests` | Подождать |
| `URL using bad/illegal format` | Кавычки у файлов с пробелами/кириллицей |
| Файл > 50 MB | Сжать или разбить |
