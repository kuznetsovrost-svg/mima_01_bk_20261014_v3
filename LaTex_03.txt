# LaTeX — заполненный шаблон отчёта (пример)
Версия 03, 2026-07-08. Продолжение LaTex_02.txt (общая теория) и LaTex_02.txt (конвейер).
Здесь — конкретный работающий документ, который можно скомпилировать и получить PDF.

## 1. Что внутри примера

Условный отчёт «Анализ продаж по регионам за II квартал 2026» содержит:
- титульный лист с авторами и датой
- аннотацию (abstract)
- оглавление (автоматическое)
- 3 раздела с подразделами
- 2 разные таблицы: `booktabs + siunitx` (числовая) и `tabularx` (с длинными ячейками)
- один рисунок (условный PNG/SVG)
- 2 формулы с перекрёстными ссылками
- список литературы (BibTeX)
- сноску

Документ рассчитан на **XeLaTeX** (русский язык + системные шрифты) и на **pdfLaTeX** (латиница). Один и тот же `.tex` собирается обоими движками — для русского нужна XeLaTeX-версия с `polyglossia`.

\subsection{Расчётные формулы}

Доля региона в~общей выручке рассчитывается по~формуле:

\begin{equation}\label{eq:share}
  S_i = \frac{R_i}{R_\text{total}} \times 100\,\%
\end{equation}

где~$R_i$~--- выручка~$i$-го региона, $R_\text{total}$~---
суммарная выручка. Для~Центрального~ФО: $S = 14{,}1 / 31{,}6
\times 100 = 44{,}6\,\%$.

Среднемесячный темп роста (CMGR) считается как:

\begin{equation}\label{eq:cmgr}
  \text{CMGR} = \left(\frac{R_\text{end}}{R_\text{start}}\right)^{1/n} - 1
\end{equation}

где~$n$~--- число~периодов.

## 4. Как скомпилировать — три способа

### 4.1. Прямой вызов XeLaTeX (две компиляции подряд)
```bash
cd report
xelatex -interaction=nonstopmode report.tex
xelatex -interaction=nonstopmode report.tex
# → report.pdf
```

### 4.2. latexmk (автоматически считает число проходов)
```bash
latexmk -xelatex -interaction=nonstopmode report.tex
# Один проход, но latexmk сам прогонит столько раз, сколько нужно
```

### 4.3. Makefile
```makefile
ENGINE ?= xelatex
TARGET := report
.PHONY: all clean view

all: $(TARGET).pdf

$(TARGET).pdf: $(TARGET).tex
	latexmk -$(ENGINE) -interaction=nonstopmode $<

view: $(TARGET).pdf
	xdg-open $< 2>/dev/null || open $<  # macOS

clean:
	latexmk -CA
	rm -f $(TARGET).pdf $(TARGET).aux $(TARGET).log $(TARGET).toc
```

```bash
make              # собрать
make ENGINE=pdflatex   # через pdfLaTeX
make view         # открыть PDF
make clean        # очистить
```

## 5. Минимальный Python-конвейер для автогенерации

`build_report.py`:
```python
#!/usr/bin/env python3
"""Генерация report.pdf из шаблона и данных."""
import subprocess
import sys
from pathlib import Path
from jinja2 import Environment, FileSystemLoader

LATEX_ESCAPE_MAP = {
    '\\': r'\textbackslash{}', '&': r'\&', '%': r'\%', '$': r'\$',
    '#': r'\#', '_': r'\_', '{': r'\{', '}': r'\}',
    '~': r'\textasciitilde{}', '^': r'\textasciicircum{}',
}
def latex_escape(value):
    if value is None:
        return ''
    return str(value).translate(str.maketrans(LATEX_ESCAPE_MAP))

def render_template(data: dict) -> str:
    env = Environment(
        loader=FileSystemLoader('templates'),
        autoescape=False,
        trim_blocks=True,
        lstrip_blocks=True
    )
    env.filters['latex_escape'] = latex_escape
    template = env.get_template('report.tex.j2')
    return template.render(**data)

def compile_pdf(tex_path: Path, engine: str = 'xelatex', passes: int = 2) -> Path:
    for i in range(passes):
        print(f'>>> Pass {i+1}/{passes}: {engine}')
        result = subprocess.run(
            [engine, '-interaction=nonstopmode', '-halt-on-error',
             '-output-directory', str(tex_path.parent), tex_path.name],
            capture_output=True, text=True
        )
        if result.returncode != 0:
            print('STDOUT (last 2000 chars):')
            print(result.stdout[-2000:])
            print('STDERR (last 2000 chars):')
            print(result.stderr[-2000:])
            sys.exit(f'LaTeX failed (exit {result.returncode})')
    return tex_path.with_suffix('.pdf')

def main():
    data = {
        'report': {
            'title':       'Анализ продаж по регионам за II квартал 2026',
            'subtitle':    'Отчёт подготовлен для совета директоров',
            'authors':     'Иванов И.И., Петров П.П.',
            'date':        '8 июля 2026 г.',
            'company':     'ООО «Пример»',
            'confidential':'Конфиденциально',
        },
        'regions': [
            {'name': 'Центральный ФО',     'revenue': 14.1, 'growth': 18.2,
             'orders':  872, 'avg_check': 16.2, 'margin': 35.0},
            {'name': 'Северо-Западный ФО', 'revenue':  6.8, 'growth': 11.5,
             'orders':  421, 'avg_check': 16.2, 'margin': 33.4},
            {'name': 'Приволжский ФО',     'revenue':  5.2, 'growth':  8.3,
             'orders':  338, 'avg_check': 15.4, 'margin': 31.7},
            {'name': 'Уральский ФО',       'revenue':  4.1, 'growth':  6.0,
             'orders':  267, 'avg_check': 15.4, 'margin': 30.2},
            {'name': 'Дальневосточный ФО', 'revenue':  1.4, 'growth':  2.1,
             'orders':   91, 'avg_check': 15.4, 'margin': 28.9},
        ],
    }
    tex = render_template(data)
    build_dir = Path('build')
    build_dir.mkdir(exist_ok=True)
    tex_path = build_dir / 'report.tex'
    tex_path.write_text(tex, encoding='utf-8')
    pdf = compile_pdf(tex_path, engine='xelatex', passes=2)
    print(f'\nГотово: {pdf} ({pdf.stat().st_size:,} байт)')

if __name__ == '__main__':
    main()
```

## 6. Что показывает каждая секция шаблона

| Секция | Что демонстрирует | Пакеты |
|---|---|---|
| Преамбула | Шрифты, языки, пакеты, настройки | `fontspec`, `polyglossia`, `geometry`, `microtype` |
| `\newcommand` | Переменные шаблона | базовый LaTeX |
| `titlepage` | Титульный лист без класса `titlepage` | базовый LaTeX |
| `abstract` | Аннотация | базовый LaTeX |
| `\tableofcontents` | Автоматическое оглавление | базовый LaTeX |
| `\section / \subsection` | Нумерация + ToC | базовый LaTeX |
| `itemize / enumerate` | Списки с настройкой отступов | `enumitem` |
| `tabular + booktabs + siunitx` | **Таблица 1**: числа, выравнивание по запятой | `booktabs`, `siunitx`, `multirow` |
| `tabularx` | **Таблица 2**: авто-ширина колонки | `tabularx` |
| `xcolor` + `\rowcolor` | Подсветка строки «Итого» | `xcolor` |
| `figure + includegraphics` | График | `graphicx` |
| `equation` + `\label` | Формулы с перекрёстными ссылками | `amsmath` |
| `\cref` / `\Cref` | «умные» перекрёстные ссылки | `cleveref` |
| `\footnote` | Сноска | базовый LaTeX |
| `thebibliography` | Список литературы (без BibTeX) | базовый LaTeX |

## 7. Особенности русского языка в шаблоне

### 7.1. Неразрывные пробелы (`~`)
После коротких слов: `стр.~\pageref{...}`, `т.~д.`, `т.~е.`, `и~т.~д.`,
`на~II~квартал`, `ООО<<Пример>>`. В~шаблоне это уже расставлено.

### 7.2. Кавычки-ёлочки
В~XeLaTeX с~`polyglossia` + русским шрифтом (PT~Serif, PT~Sans, PT~Mono)
работают ``...''` (верхние) и~`<<...>>` (нижние) как~активные символы.

### 7.3. Кириллические единицы измерения
В~шапках таблиц: `млн\,₽`, `тыс.\,₽`, `\%`. Между единицей и~числом — `\,`
(тонкий пробел). Между числом и~\% в~русской типографике — неразрывный пробел.

### 7.4. Переносы
XeLaTeX с~`polyglossia` и~шрифтом, содержащим кириллицу, выполняет
переносы автоматически. Если шрифт не~содержит правил переноса,
используйте \texttt{babel-russian} даже с~XeLaTeX.

## 8. Тестовая компиляция на mima_g_01 (если TeX Live установлен)

```bash
ssh mima-g-01
# Установка (если ещё нет)
sudo apt-get install -y texlive-xetex texlive-latex-extra \
     texlive-fonts-recommended texlive-lang-cyrillic \
     texlive-fonts-extra latexmk

# Сборка
cd /tmp && mkdir report && cd report
# (скопировать report.tex и images/ из этого примера)
xelatex -interaction=nonstopmode report.tex
xelatex -interaction=nonstopmode report.tex
ls -lh report.pdf
# → готовый PDF, обычно 200-400 КБ
```

## 9. Сколько занимает компиляция

| Конфигурация | Время | Размер PDF |
|---|---|---|
| Минимальная (без графики, без `microtype`) | 0,5~с | 50–80 КБ |
| Средняя (этот шаблон) | 2–4~с | 200–400 КБ |
| Большая (диссертация 200~стр., TikZ) | 30–90~с | 5–15 МБ |

## 10. Что чаще всего «ломается»

| Симптом | Причина | Решение |
|---|---|---|
| `Package fontspec Error: The font "PT Serif" cannot be found` | Шрифт не установлен | `apt install fonts-paratype` или заменить на `Liberation Serif` |
| `LaTeX Error: File 'polyglossia.sty' not found` | TeX Live без `lang-cyrillic` | `apt install texlive-lang-cyrillic` |
| `! Undefined control sequence` | Опечатка или пропущенный пакет | Проверить преамбулу |
| `Missing $ inserted` | `_` или `^` в~тексте | Эскейпить: `\_`, `\^` |
| Кириллица отображается квадратами | Шрифт не поддерживает кириллицу | Сменить `\setmainfont{}` на кириллический |
| Оглавление пустое после первой компиляции | Один проход — `toc` не сформирован | Запустить `xelatex` второй раз |
| Перекрёстные ссылки показывают `??` | `\label` стоит после `\caption` или нет второй компиляции | `\label` после `\caption` ИЛИ запустить ещё раз |

## 11. Как модифицировать шаблон

### 11.1. Добавить ещё одну таблицу
Скопировать блок `\begin{table}[htbp] ... \end{table}` и~поменять `caption`,
`label`, содержимое `tabular`. Стили `booktabs` + `siunitx` применять везде.

### 11.2. Добавить приложение
```latex
\appendix
\section{Подробные расчёты}
\cref{app:full} содержит полную таблицу.
```

### 11.3. Подключить BibTeX вместо `thebibliography`
Заменить блок `\begin{thebibliography}` на:
```latex
\bibliographystyle{plain}
\bibliography{bibliography}   % файл bibliography.bib рядом
```
Запуск:
```bash
xelatex report.tex
bibtex report
xelatex report.tex
xelatex report.tex
```
Либо через `biber` (пакет `biblatex`):
```bash
xelatex report.tex
biber report
xelatex report.tex
xelatex report.tex
```
