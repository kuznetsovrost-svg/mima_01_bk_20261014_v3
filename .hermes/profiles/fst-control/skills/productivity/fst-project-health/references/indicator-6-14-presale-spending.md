# Индикатор 6.14 «Расход лимита пресейла»

**Реализован 2026-09-03.** См. `scripts/project_indicators.py::check_presale_limit_spending`.

#### Назначение

Контроль расхода лимита пресейла. Если лимит превышен — информация для руководства, которое может сознательно на это идти.

#### Получение данных

- **A = PresaleLimit** (через `get_project_property(sid, project_id, "PresaleLimit")` — поле «Лимит на пресейл, руб.»).
- **B = Σ расходов** с меткой «Пресейл» из `ProjectBudgetCompleteBusiness`:
  - Фильтр: `budgettype == "Расход расчет по ресурсам"` (расходы на трудозатраты)
  - Метка «Пресейл»: `ispresalebudget=True` ИЛИ `PointTagName == "Пресейл"`
  - Приоритет по суммам (Pitfall #121): `payfactsum > payforecastsum > payplansum > actfactsum > actforecastsum > actplansum > 0`

#### Уточнения пользователя (Q1-Q5, 2026-09-03)

| Q | Ответ | Заметка |
|---|-------|---------|
| Q1 | Для **всех** стадий ЖЦ | Пользователь сам отменил первоначальное уточнение «только для Пресейл» |
| Q2 | Готовые суммы из `ProjectBudgetCompleteBusiness` | **Не** умножаем часы на ставку |
| Q3 | Только из бюджетного представления | Если данных нет — расход = 0 |
| Q4 | Расходы (не трудозатраты) | Суммы из `pay*sum / act*sum` |
| Q5 | Δ = Лимит - Потрачено | Может быть отрицательным (перерасход) |

#### Интерпретация

Подкраска строки **всегда нейтральная** (информационный индикатор). Даже если Δ < 0 (перерасход) — это **НЕ** нарушение, а информация.

#### Вывод

Колонка «Результат» (конкатенированная строка):

```
Лимит:2 700 000 руб./Потрачено:7 057 951 руб./Δ=-6 057 951 руб.
```

Без вложенной таблицы.

#### Формат чисел

Все значения в **рублях** (без «млн.»), в отличие от 6.9 и 6.10 которые используют формат `X,YZZ млн. руб.`:

```python
def fmt_rub(v):
    if v == 0:
        return "0 руб."
    return f"{int(round(v)):,} руб.".replace(",", " ")
```
