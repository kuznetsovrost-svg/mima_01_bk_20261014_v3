# Section 6 HTML rendering bug — 16 indicators (2026-09-03)

## Symptom (от ROSTISLAV, 2026-09-03)

В сгенерированном HTML (e.g. `project_504-595_report.html`) раздел 6 «Показатели проекта» имеет 4 бага:

1. **Нет раскрытия вложенных таблиц** — клик по «Детали» не открывает вложенную таблицу.
2. **Скрыты подпункты 6.3, 6.4, 6.6, 6.8, 6.15, 6.16** (визуально отсутствуют / нулевая высота).
3. **Нет кнопки ▼ в колонке «Детали»** (ячейка пустая).
4. **Нет подсветки строк кроме 6.1** (фон `critical/substantial/informational` не применяется).

Подпункты, у которых ЕСТЬ вложенные таблицы (по дизайну): **6.2, 6.3, 6.4, 6.5, 6.6, 6.7, 6.8, 6.15, 6.16**.
Подпункты БЕЗ вложенных таблиц (простые строки): 6.1, 6.9, 6.10, 6.11, 6.12, 6.13, 6.14.

## Root cause (build_html_report.py, function around lines 335-455)

Генератор использует **двойную обёртку** для индикаторов с вложенной таблицей:

```html
<tr class='indicator-main-row' data-status="...">   <!-- ВНЕШНЯЯ строка -->
  <td colspan='4' style='padding: 0;'>
    <details class='row-details-indicator'>
      <summary class='hidden-summary'></summary>     <!-- display:none -->
      <div class='indicator-main-row-content'>
        <table class='tbl tbl-indicators-main-row'> <!-- ВНУТРЕННЯЯ таблица -->
          <tr>
            <td data-status="...">6.X</td>          <!-- status на td, не на tr -->
            ...
            <td class='col-details'><span>▼</span></td>
          </tr>
        </table>
        <div class='tbl-nested-wrapper'>...         <!-- display:none по CSS -->
```

**Почему всё ломается:**

| Bug | Причина |
|---|---|
| (1) Не раскрывается | `<summary class='hidden-summary'>` имеет `display:none !important` — нативный `<details>` без видимого `<summary>` не реагирует на клик по `▼` (CSS только меняет цвет маркера, не открывает details). |
| (2) Скрытые подпункты | Внешняя `<tr class='indicator-main-row' colspan='4' style='padding:0'>` рендерится в «одну строку с мини-таблицей» — конфликт colspan с colgroup + padding:0 ломает layout. Внешняя `<td class='col-details'>` главной таблицы **пустая**, поэтому треугольник не виден на верхнем уровне. |
| (3) Нет ▼ в основной строке | Маркер `▼` есть только внутри вложенной таблицы, а внешняя `<td class='col-details'></td>` главной `tbl-indicators` пустая. Пользователь кликает по пустой ячейке. |
| (4) Нет подсветки | CSS-правила `tr[data-status="critical"]` ожидают атрибут на `<tr>`, но код ставит его на `<td>` внутри вложенной таблицы. |

## Правильная структура (как должно быть)

**Внешняя `<tr>` главной таблицы `tbl-indicators` = основная строка индикатора** (с `data-status`, с треугольником ▼ в `col-details`). Вложенная таблица — **отдельная `<tr>` главной таблицы** под ней, видимая только при раскрытии `<details>`.

Упрощённо:

```html
<tbody>
  <!-- Простой индикатор (нет вложенной таблицы) -->
  <tr data-status="critical">
    <td>6.1</td>
    <td>Юрлицо...</td>
    <td>Нет</td>
    <td class="col-details"></td>            <!-- пустая -->
  </tr>

  <!-- Индикатор с вложенной таблицей — ДВЕ строки, обёрнутые в <details> -->
  <tr data-status="critical" class="indicator-row-with-details">
    <td>6.3</td>
    <td>Прогнозы...</td>
    <td>Вопросы, 703 ч</td>
    <td class="col-details"><span class="col-details-marker">▼</span></td>
  </tr>
  <tr class="row-details-row">               <!-- скрыта пока details закрыт -->
    <td colspan="4">
      <table class="tbl-nested">...</table>
    </td>
  </tr>
</tbody>
```

`<details>` оборачивает **только контент вложенной строки** (или используется нативный `<details>` вокруг всей пары `<tr>` через CSS-свойство `display: contents`).

## Lesson for future sessions — workflow pitfall

**Pitfall #NEW: «Это не эталон!»**

- Если пользователь присылает файл с версией в имени (e.g. `_33_.html`), **не считать его автоматически эталоном**.
- Прежде чем анализировать «что не так» — уточнить, является ли файл эталоном, текущей версией с ошибками или чем-то ещё.
- При работе с отчётами fst-project-health ВСЕГДА спрашивать: «Где эталон? Какие конкретно ошибки ты видишь?»
- Не тратить время на догадки типа «возможно это эталон V6» — пользователь даст прямой ответ.

Также для секции 6:
- **Pitfall #TBD**: двойная обёртка `<tr colspan='4'>` + вложенная `<table>` ломает HTML рендеринг. Использовать только одноуровневую структуру.
- **Pitfall #TBD**: `data-status` должен быть на `<tr>`, не на `<td>` — иначе CSS-правила `tr[data-status="..."]` не работают.
- **Pitfall #TBD**: `<summary class='hidden-summary'>` с `display:none !important` ломает нативный `<details>`. Если нужно скрыть summary — использовать `width:0;height:0;opacity:0;position:absolute`, чтобы сохранить кликабельность.
