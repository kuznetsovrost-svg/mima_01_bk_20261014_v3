# CHANGELOG — fst-project-health-word

## v1.0.20 (2026-09-24)

**Исправление нумерации под MD v1.0.19**

- **Заголовки разделов**: перенумерованы по новой схеме MD: «6. Показатели проекта», «7. Финансы», «8. Тех. данные», «9. Индикатор» (вместо старых «6. Финансы», «7. Тех. данные», «8. Сводка»).
- **Добавлен раздел 6 «Показатели проекта» (16 индикаторов)** с вложенными таблицами `### 6.N` (отображаются раскрытыми, без `<details>` — специфика DOCX).
- **Добавлен раздел 8 «Тех. данные»** (3-кол таблица `# | Показатель | Значение`).
- **Добавлен раздел 9 «Индикатор»** (3-кол таблица `# | Название | Статус` + статус-бокс).
- **Добавлен парсинг YAML front-matter** (`generator`, `snapshot_timestamp`).
- **Добавлен параметр «Источник» в метаданных**:
  - Live (`generator="fst-project-health"`): «MCP (в реальном времени)».
  - Snapshot (любой другой `generator`): «Слепок от YYYY-MM-DD HH:MM:SS» (если есть `snapshot_timestamp`).
- **KNOWN_HEADERS**: убран дубликат ключа `4`, добавлен ключ `3` для Тех. данных.
- **scope** в метаданных обновлён: «разделы 3-9» (вместо «3-7»).
- **Добавлен пакетный скрипт** `scripts/build_word_from_snapshot.sh`: цепочка `fetch_snapshot → build_word` для нескольких проектов одной командой.

## v1.0.0 (2026-09-15)

- Выделен из `fst-project-health` как отдельный скилл для DOCX-отчётов.
