# DEPRECATED 2026-09-24

Скилл `fst-project-health-snapshot` **больше не используется** в актуальном pipeline.

## Почему отключён

Изначально этот скилл собирал **JSON-слепки** состояния проектов в карточки MCP
(категория «Документы ИИ»), чтобы потом на их основе строить **трендовые отчёты**.

Сейчас в pipeline используется **MD-формат** (а не JSON), потому что:

1. **MD — source of truth**: один MD-файл самодостаточен (YAML front-matter + секции + таблицы).
2. **Читается глазами** в любом редакторе (Notepad++, vim, VS Code) — JSON для человека не читаем.
3. **Унифицирован с HTML и DOCX**: один и тот же MD собирает и HTML, и DOCX, и тренды.
4. **Round-trip работает**: write→read→HTML с верификацией SHA256 (подтверждено в ходе
   сегодняшних проверок 2026-09-24).

## Замена

Вместо `fst-project-health-snapshot` используйте **`fst-project-health-snap-md`**:

| Что делали | Что делать сейчас |
|---|---|
| `python3 fst-project-health-snapshot/scripts/snapshot.py --code 504-595` | `python3 fst-project-health-snap-md/scripts/run_snap_md.py --code 504-595` |
| Получали JSON в MCP карточке проекта | Получаем MD (самодостаточный) в MCP карточке проекта |
| Для чтения нужно было парсить JSON | Для чтения нужен только текстовый редактор |

Для извлечения MD-слепков из MCP и построения HTML/DOCX отчёта по нему
используйте **`fst-project-health-from-md-snapshot`**.

- Запускать **не рекомендуется** — никто не тестировал на актуальной версии MD.

## Если у вас в MCP остались JSON-слепки

Они не мешают — категория «Документы ИИ» может содержать смешанные форматы.
Для анализа трендов:

1. Скачайте MD-слепки через `fst-project-health-from-md-snapshot/scripts/fetch_snapshot.py`.
2. Старые JSON-слепки можно либо игнорировать, либо вручную сконвертировать в MD.
