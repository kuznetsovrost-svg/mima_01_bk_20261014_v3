# Changelog — fst-project-health-tests

## v1.0.19 — 2026-09-24

**Первая версия.**

### Что появилось

- **6 групп тестов** в отдельных файлах:
  - `test_01_regression.py` — Уровень 1 (3 теста)
  - `test_02_mcp.py` — Уровень 4 (16 тестов)
  - `test_03_snap_md.py` — Уровень 2 (9 тестов)
  - `test_04_from_md.py` — Уровень 3 (15 тестов)
  - `test_05_cross_skill.py` — Уровень 5 (4 теста)
  - `test_06_invariants.py` — Уровень 6 (6 тестов)
- **Свой `run_all_tests.py`** (не pytest) — переносимо, без зависимостей.
- **Группы тестов запускаются отдельно** (`--group <name>`), чтобы не
  было таймаутов на полном прогоне.
- **MCP-тесты по умолчанию ВКЛЮЧЕНЫ** (группа `mcp`).
- **Never-fail для тестов**: `@_transient_safe` декоратор ловит
  ReadTimeout/ConnectionError и превращает в SKIP.
- **Retry 3×** на каждый MCP-вызов (через `_retry_mcp`).
- **Логи в logs/tests.log** — накапливаются, отдельные секции для
  каждого прогона.
- **`scripts/rotate_logs.py`** — ротация логов тестов с политикой
  `>100d` → archive/YYYY-MM/, `>400d` → удалить (намеренно короче,
  чем в основных скиллах 400d/1500d).
- **Коды возврата**: 0 (OK), 1 (FAIL), 2 (все MCP SKIPPED).
- **`tests/test_project.py`** — настройка тестового проекта, скопирован
  в каждый из 2 скиллов для автономности.
- **SKILL.md / README.md / playbook.md** — с прецедентами по времени
  для каждого теста.
