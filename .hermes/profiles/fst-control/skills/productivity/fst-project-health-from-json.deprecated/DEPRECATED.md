# DEPRECATED — 2026-09-24

Этот скилл **не используется с 24 сентября 2026**.

## Почему

При разработке семейства `fst-project-health-*` планировалось, что
слепки состояния проектов будут храниться в карточке в формате JSON.
На практике выяснилось, что **MD-слепки удобнее** (читаются людьми,
являются полным source of truth для HTML-рендера), поэтому:

- формат хранения сменился с JSON на MD;
- `fst-project-health-snapshot` остался (для тех, кому нужен JSON-формат),
  но это уже **другая история**;
- `fst-project-health-from-json` не удалось довести до рабочего состояния —
  HTML-рендеринг из JSON-слепков не был доделан.

## Чем заменить

**`fst-project-health-from-md-snapshot`** — новый скилл, который:
- читает MD-снимок из карточки проекта в MCP (через `list_files` +
  `resources/read`);
- строит HTML **только** из этого MD (без обращения к live MCP);
- поддерживает режимы выбора снимка: `--last`, `--first`, `--nearest`, `--exact`, `--pick`;
- готов к массовым вызовам через `--codes` для трендового анализа.

## Что делать с этим каталогом

- **Не удалять.** Архив с содержимым лежит в
  `/tmp/fst-project-health-from-json.deprecated.2026-09-24.tar.gz`.
- Использовать скилл **не нужно** — все сценарии покрыты
  `fst-project-health-from-md-snapshot`.
- При миграции на новую машину — **не копировать** этот каталог.
