PLAYBOOK-стиль (пользователь явно требует): общий обзор → API → скрипты с LOC/размером → переиспользуемые методы → особенности → прецеденты по времени → сценарии (идеальный/частый/опечатка) → где лежит. **Повторения между независимыми PLAYBOOK допустимы и желательны** — «не бойся повторяться из одного PLAYBOOK в другой: другие пользователи могут читать только какой-то один». Документация честная: никаких выдуманных зависимостей, сверять с кодом. Рубрикатор отдельным файлом, имена PLAYBOOK понятные без открытия.
