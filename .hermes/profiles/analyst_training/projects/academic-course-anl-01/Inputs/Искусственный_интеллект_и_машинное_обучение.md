**Профессии, которые могут выбрать выпускники**

*Учёный по данным (data scientist):*
Проясняет требования к бизнес-задаче и переводит её в математическую плоскость
Готовит данные для решения задачи
Анализирует и структурирует данные
Строит модель машинного обучения, которая будет решать задачу
Проверяет правильность работы модели

*Инженер по данным (data engineer):*
Собирает и обрабатывает большие данные
Загружает данные в модель для анализа
Организовывает хранение и дальнейшее использование данных в бизнесе

*Аналитик больших данных:*
Собирает данные
Занимается выборкой и сортировкой информации для проведения аналитики
Ищет закономерности в наборах данных
Виртуализирует данные для лучшего выявления тенденций и представления результатов анализа
Формулирует прогнозы и предположения по оптимизации бизнес-процессов
Разрабатывает и тестирует различные модели машинного обучения

*Программист широкого профиля:*
Занимается разработкой алгоритмов и компьютерных программ
Создаёт ПО для различных компаний и организаций
Управляет базами данных
Поддерживает работу существующих систем

*Архитектор систем искусственного интеллекта:*
Определяет архитектуру ИИ и выбирает подходящие технологии
Проводит аудит инструментов и методов ИИ в области данных, моделей и разработки ПО
Приводит техническую реализацию в соответствие с существующими и будущими требованиями
Взаимодействует с дата-сайентистами и другими специалистами в области ИИ


###Возможный карьерный путь выпускников
Выпускники могут пройти следующий карьерный путь: программист широкого профиля → системный аналитик →разработчик инфраструктуры больших данных → архитектор систем искусственного интеллекта.

###Результаты обучения по профилю
Выпускники имеют навыки в решении прикладных задач и аккумуляции знаний для использования искусственного интеллекта при выработке управленческих решений.
Выпускники обладают умениями в решении прикладных задач естествознания с использованием методов искусственного интеллекта и машинного обучения.
