## 3. Ключевые преимущества программы подготовки

1. **Партнёрство с Яндексом.** Яндекс — это production-grade full-stack экосистема (Yandex Cloud, YDB, YaML, ARIA). Студенты получают доступ к современным инструментам и практикам.

2. **Полный full-stack охват.** Дисциплины по frontend, backend, mobile (Android), desktop, администрированию. Это даёт выпускнику широкую инженерную базу.

3. **Современная архитектура ПО:** «Архитектура клиент-серверных приложений» (сем. 5, курсовая), «Проектирование клиент-серверных систем» (сем. 7, экзамен + курсовая), «Системная и программная инженерия» (сем. 6), «Микросервисная архитектура» — это критически важные дисциплины для архитектора AI-агентов (агенты строятся как распределённые системы).

4. **Сильный software engineering фундамент:** «Технология разработки программных приложений» (сем. 4), «Тестирование и верификация программного обеспечения» (сем. 5), «Конфигурационное управление» (сем. 3), «Системное администрирование» (сем. 6), «Программные средства защиты информации» (сем. 6). Это даёт качественную инженерную культуру.

5. **Java как основной язык** (сем. 3–4 — «Программирование на языке Джава»), плюс Python (сем. 4 — «Программирование на языке Питон»), плюс Kotlin (в родственной программе №5). Это разнообразный языковой стек.

6. **Проектирование информационных систем (сем. 6)** + **Анализ и концептуальное моделирование систем (сем. 4)** — это классический software architecture, нужный для архитектора агента.

7. **Большой блок по базам данных:** «Проектирование баз данных» (сем. 4), «Разработка баз данных» (сем. 5) — база для современных RAG-агентов.

8. **Разработка под IoT:** «Технологические основы интернета вещей» (сем. 5), «Информационные технологии Интернета вещей» (сем. 5–6) — это даёт опыт работы с edge-устройствами, что релевантно для edge-агентов.

9. **Самый высокий проходной балл (288).** Программа привлекает сильных абитуриентов.

## 4. Слабые места программы подготовки

1. **AI-тематика — почти полностью отсутствует.** Только «Системы искусственного интеллекта и большие данные» (сем. 2–3) и «Машинное обучение» (сем. 5–6). Это **минимальное** покрытие AI. Программа не готовит архитекторов AI, она готовит классических full-stack инженеров.

2. **Нет deep learning / нейронных сетей как дисциплины.** Только общее «Машинное обучение» (зачёт, 2 семестра).

3. **Нет LLM, prompt-engineering, RAG, agentic-patterns.** Это не та программа.

4. **Нет multi-agent, agentic AI.** Полностью отсутствует.

5. **Нет AI safety / alignment / ethics.**

6. **Нет HPC / параллельных вычислений.** Программа для full-stack, а не для high-performance.

7. **Мало математики.** Математический анализ — только сем. 1–3; нет функционального анализа, нет оптимизации, нет теории случайных процессов. ML-часть опирается на «Машинное обучение» как чёрный ящик.

8. **Java как основной язык** — не оптимально для AI-агентов (Python/TypeScript актуальнее).

9. **VR/AR** (сем. 6 — «Моделирование сред и разработка приложений виртуальной и дополненной реальности») — нишевая дисциплина, не для AI-агентов.

10. **Стоимость 450 000 ₽** — самая высокая из 5, при этом наименьший возврат для AI-агент карьеры.

## 6. Близость типовых профессий к задаче стать архитектором AI агентов

| Профессия | Близость |
|---|---|
| Разработчик web/mobile/desktop приложений | 5/10 — full-stack инженер, не AI |
| Разработчик клиент-серверных систем | 6/10 — это архитектура систем, AI там побочно |
| Проектировщик информационных систем | 6/10 — software architect, не AI architect |
| Специалист по программной инженерии | 5/10 — generic software engineer |

| Администратор клиент-серверных систем | 4/10 — это про администрирование |

**Ключевое наблюдение:** ни одна профессия не про AI. Все — про классический software engineering. Карьерный трек явно уходит в **«архитектор программного обеспечения»**, что близко к «AI-агент архитектору» по навыкам архитектуры, но не по домену.

**Итоговая оценка: 5/10.** Программа даёт архитектурную базу, но не AI-домен.
