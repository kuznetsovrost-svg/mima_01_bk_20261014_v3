## 3. Ключевые преимущества программы подготовки

1. **Сильная методологическая подготовка по жизненному циклу ПО.** «Моделирование программных систем» (сем. 4), «Стандартизация и сертификация ПО» (сем. 7), «Сопровождение программных систем» (сем. 7), «Оценка параметров функционирования программных систем» (сем. 7), «Проектирование программных систем» (сем. 7, экзамен + курсовая), «Управление ИТ-проектами» (сем. 7). Это даёт выпускнику системный взгляд на software lifecycle.

2. **Сертификация от Samsung.** IT Академия Samsung интегрирует треки «Мобильная разработка» в дисциплины, даёт бесплатную сертификацию. Это конкурентное преимущество при трудоустройстве.

3. **Kotlin как основной язык мобильной разработки** (сем. 4, сем. 5–6) — современный стек для Android. Kotlin — также язык для современных backend-сервисов (Ktor).

4. **Продуктовый менеджмент:** «Управление разработкой и реализацией проекта» (родств. программа), «Управление ИТ-проектами» (сем. 7), «Информационный менеджмент программных продуктов и систем» (родств.). Программа готовит **product owner / project manager**.

5. **Бесплатный доступ к международным и отечественным библиотекам стандартов в сфере ИТ.** Это уникальное преимущество — студенты работают с ГОСТами, ISO, IEEE-стандартами напрямую.

6. **«Архитектура операционных систем мобильных устройств» (сем. 3, экзамен + курсовая).** Понимание мобильных ОС — это платформенная экспертиза, нужная для edge-агентов.

7. **«Распределенные системы управления базами данных» (сем. 6, экзамен).** Распределённые СУБД — база для агентских data-систем.

8. **«Проектирование и разработка кроссплатформенных мобильных приложений» (сем. 7, экзамен)** — кроссплатформенная разработка, релевантная для агентских клиентов.

9. **«Микросервисная архитектура» (сем. 7, экзамен).** Это напрямую релевантно для архитектуры AI-агентов.

10. **Разнообразие языков:** Java (сем. 3), Kotlin (сем. 4–7), Python (сем. 4). Это даёт polyglot-возможности.

## 4. Слабые места программы подготовки

1. **AI-тематика — минимальна.** Только «Системы искусственного интеллекта и большие данные» (сем. 2–3, экзамен) и «Машинное обучение» (сем. 5–6, зачёт). Это значительно меньше, чем в программе №2 («Искусственный интеллект»).

2. **Нет LLM, prompt-engineering, RAG, agentic-patterns, multi-agent.** Полностью отсутствует современный AI-agent-stack.

3. **Нет deep learning / нейронных сетей как отдельной дисциплины.** «Машинное обучение» — зачёт, поверхностный обзор.

4. **Нет HPC / параллельных вычислений.** Программа для мобильной/корпоративной разработки, не для high-performance.

5. **Нет AI safety / alignment / ethics.**

6. **Мало математики.** Только стандартный набор: линейная алгебра (сем. 1–2), математический анализ (сем. 1–3), теория вероятностей (сем. 4), вычислительная математика (сем. 4). Нет функционального анализа, нет оптимизации, нет теории случайных процессов.

7. **Mobile-фокус ограничивает.** Программа готовит мобильных разработчиков, а не универсальных архитекторов. Kotlin и Android-экосистема — это узкая специализация.

8. **Продуктовый менеджмент — это про бизнес, не про AI.** Полезный навык, но не для AI-агент-архитектора.

9. **Стоимость 450 000 ₽** при этом наименьший возврат для AI-агент карьеры.

10. **Моделирование VR/AR (родств. программа)** — нишевая тема.
