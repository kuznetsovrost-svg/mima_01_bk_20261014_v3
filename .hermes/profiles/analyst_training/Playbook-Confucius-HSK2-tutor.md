# Playbook: как AI-ассистент помогает слушателю Института Конфуция готовиться к HSK2

> **Цель документа:** подробно описать, что конкретно я могу делать для слушателя курсов Института Конфуция, готовящегося к сдаче HSK2 — где я сильный помощник, где я дополняю тьютора, а где живого преподавателя заменить нельзя.
>
> **Важно:** документ построен на открытых источниках. Конкретный Институт Конфуция, программу, преподавателя и расписание я не знаю — playbook описывает универсальный формат, который адаптируется.

---

## Часть 1. Справка: Институт Конфуция и HSK2

### 1.1. Институт Конфуция — что это

**Институт Конфуция** (孔子学院) — сеть образовательных учреждений, созданных при поддержке КНР для продвижения китайского языка и культуры за рубежом.

| Факт | Значение |
|---|---|
| Год основания программы | 2004 (при поддержке Министерства образования КНР, Hanban / Centre for Language Education and Cooperation) |
| Расположение в РФ | СПбГУ, НГЛУ (Нижний Новгород), ДВФУ (Владивосток), ВШЭ (Москва), МГУ, Казанский федеральный, КарТУ (Казахстан) и др. — всего >25 точек |
| Что делает | Курсы китайского, подготовка к HSK, культурные мероприятия, лагеря в Китае, стажировки |
| Связь с HSK | Являются центрами тестирования HSK (а некоторые — HSKK, YCT, BCT, CTCSOL) |
| Типичный курс инструкции HSK2 (на примере ВШЭ) | 136 академических часов, из них 96 аудиторных; 3-3.5 месяца; 2 занятия по 4 часа в неделю; всего 24 занятия |

**Что важно понимать для playbook:**
- Институт Конфуция — это **не только курсы**, но и **центр тестирования**, поэтому у них есть методическая база для подготовки
- Занятия строятся вокруг **учебников HSK Standard Course** (разработаны специально под экзамен)
- Преподаватели — обычно **носители языка** или китаисты с высокой квалификацией

### 1.2. HSK2 — что это за экзамен

**HSK** (Hanyu Shuiping Kaoshi, 汉语水平考试) — стандартизированный международный экзамен по китайскому языку. Уровни 1-6 в старом формате (HSK 2.0), 1-9 в новом (HSK 3.0).

**Формат HSK2 (HSK 2.0) — стандартный:**

| Раздел | Часть | Кол-во вопросов | Время |
|---|---|---|---|
| Аудирование (听) | Часть 1 | 10 | ~25 мин (всего) |
| | Часть 2 | 10 | |
| | Часть 3 | 10 | |
| | Часть 4 | 5 | |
| Чтение (读) | Часть 1 | 5 | 20 мин |
| | Часть 2 | 5 | |
| | Часть 3 | 5 | |
| | Часть 4 | 10 | |
| Заполнение ответного листа | — | — | 5 мин |
| **Итого** | — | **60 вопросов** | **50 минут** |

**Баллы:**
- Аудирование — 100 баллов
- Чтение — 100 баллов
- Для прохождения — минимум **120 баллов из 200**

**Что нужно знать:**

| Параметр | Значение |
|---|---|
| Словарь | **300 слов** (базовые) |
| Иероглифы | ~150 иероглифов для распознавания и письма |
| Грамматика | Базовые конструкции (см. ниже) |
| Длительность | 50 минут |
| Письменный раздел | ❌ Нет (есть отдельный HSKK для устной части) |

**⚠️ Важный нюанс:** с 2022 года Китай вводит **новый формат HSK 3.0** (9 уровней). По нему HSK2 = 500 слов, HSK3 = 750 слов. **Старый формат (HSK 2.0) сохраняется** и параллельно сдаётся. Нужно уточнить у преподавателя вашего Института Конфуция, какой формат сдаётся в вашем случае (зависит от года сдачи и центра тестирования).

**Документы и регистрация:**
- Регистрация за ~1 месяц до экзамена
- Нужен паспорт
- Стоимость зависит от центра (~$15-30)
- Результаты — через 1-2 месяца

### 1.3. Типичные ресурсы Института Конфуция для подготовки

| Ресурс | Что даёт |
|---|---|
| **HSK Standard Course 2** (учебник + рабочая тетрадь) | Основной учебник, разработан под экзамен. 15 уроков, ~1000 упражнений |
| **HSK Standard Course 2 — Teacher's Book** | Методичка для преподавателя |
| **Mock-тесты (пробные экзамены)** | 5-10 полных вариантов для тренировки |
| **Онлайн-платформы** | Часто у Институтов Конфуция есть свои LMS с дополнительными материалами |
| **Культурные мероприятия** | Праздники, фестивали, лагеря в Китае — иммерсия |

## Часть 2. Что я могу делать действенно (по разделам)

### 2.1. По разделам экзамена HSK2

| Раздел экзамена | Что я делаю хорошо | Где ограничен |
|---|---|---|
| **Аудирование** | Сгенерировать текст диалогов и упражнения «выбери картинку». Разобрать скрипт. Объяснить лексику. | Не могу воспроизвести реальный аудиофайл и оценить восприятие на слух |
| **Чтение** | Разобрать тексты HSK2, объяснить конструкции, сгенерировать вопросы на понимание | Иероглифику даю в текстовом виде, не в виде печатных текстов |
| **Письмо** | Объяснить порядок черт концептуально, дать упражнения на написание по пиньиню | Не проверю написанный от руки иероглиф визуально |
| **Устная речь (HSKK)** | Не входит в HSK2 письменный, но если будете сдавать HSKK — могу помочь с шаблонами | Произношение и интонация — моё слабое место |

### 2.2. По грамматическим темам HSK2

Основные конструкции, которые проверяются в HSK2:

| Конструкция | Пример | Как я могу помочь |
|---|---|---|
| **Приветствия, этикет** | 你好, 谢谢, 对不起, 没关系 | Дать 20-30 ситуационных диалогов |
| **Личные местоимения** | 我, 你, 他, 她, 它, 我们, 你们, 他们 | Упражнения на заполнение пропусков |
| **Счётные слова (量词)** | 一个人, 一本书, 一杯水 | Объяснить систему, дать топ-15 счётных слов с примерами |
| **Глагол-связка 是** | 我是学生 | Генерация упражнений «подставь» |
| **Конструкция 的** | 我的书, 老师的名字 | Объяснить нюансы vs 的 как «indeed» |
| **Прошедшее время с 了** | 我吃了饭 | Разбор, когда ставить/не ставить 了 |
| **Завершённость действия с 了** | 我买了两本书 | Упражнения на различение |
| **Будущее с 要...了** | 我要走了 | Сравнение с 会, 想 |
| **Конструкция 想** | 我想去北京 | + можно, 想 + 要 |
| **Вопросы с 吗** | 你是学生吗? | Упражнения |
| **Вопросы с 呢** | 我很好, 你呢? | Разбор «tag-question» использования |
| **Конструкция 有** | 我有一个弟弟 | Упражнения, отрицание 没有 |
| **Модальный глагол 能 / 会 / 可以** | 我会说中文 | Сравнение трёх модальных |
| **Конструкция 在** (место действия) | 我在学校 | Разбор локативов |
| **Предлоги 在 / 从 / 到 / 给** | 我从北京来 | Разбор каждого предлога |
| **Отрицание 不 / 没(有)** | 我不去 / 我没有书 | Главная сложность HSK2 — различение |
| **Текстовые связки** | 因为...所以..., 但是..., 和 | Упражнения на заполнение |

### 2.3. По лексике (300 слов)

Могу:
- ✅ Сгенерировать **карточки для Anki** в формате CSV / TSV по топ-50 / 100 / 300 словам
- ✅ Сгруппировать слова по темам (времена, семья, еда, числа, цвета, погода, профессии, и т.д.)
- ✅ Дать по каждому слову 3-5 примеров употребления
- ✅ Провести мини-тест на лексику
- ✅ Объяснить разницу между похожими словами (например, 看 / 看见 / 看到)

### 2.4. По иероглифике

- ✅ Объяснить **структуру иероглифа** (радикалы, фонетические и семантические компоненты)
- ✅ Дать мнемоники для запоминания (например, 好 = 女 + 子 = «женщина с ребёнком = хорошо»)
- ✅ Объяснить порядок черт концептуально (сверху вниз, слева направо, горизонтальные до вертикальных)
- ✅ Дать упражнения «соотнеси пиньинь и иероглиф»
- ❌ Не проверю написанный рукой иероглиф визуально

### 2.5. По тонам и фонетике

- ✅ Объяснить **4 тона + нейтральный** + правила изменения тонов (tone sandhi — правило третьего тона)
- ✅ Объяснить разницу между **путающими тонами** (1/2, 3/4)
- ✅ Объяснить распространённые инициали и финали
- ❌ Не воспроизведу звук и не оценю произношение

## Часть 3. Конкретные форматы работы со мной

### 3.1. Сценарии использования

| Сценарий | Как работает | Время |
|---|---|---|
| **«Объясни мне конструкцию X»** | Я даю правило + 10-20 примеров + ловушки | 5-10 мин |
| **«Дай мне 10 упражнений на тему Y»** | Я генерирую упражнения с ответами и пояснениями | 2-5 мин |
| **«Проверь мой перевод»** | Ученик присылает текст, я разбираю ошибки | 5-15 мин |
| **«Составь мне диалог на тему Z»** | Я даю диалог в формате HSK2 + пиньинь + перевод + пояснения | 2-3 мин |
| **«Разбери мне текст из учебника»** | Ученик присылает текст, я делаю пословный разбор | 5-10 мин |
| **«Сделай мне мини-тест»** | Я генерирую тест в формате HSK2 (10-30 вопросов) | 2-3 мин |
| **«Дай карточки Anki»** | Я генерирую CSV для импорта | 3-5 мин |

### 3.2. Формат ответа (что я обычно даю)

При ответе я стараюсь придерживаться структуры:

```
1. Правило / концепт (коротко)
2. Примеры (3-10 штук) — китайский + пиньинь + русский
3. Типичные ошибки
4. Сравнение с похожими конструкциями
5. Упражнения для самопроверки (если запрошены)
```

### 3.3. Что присылать ученику для максимальной пользы

| Что прислать | Зачем |
|---|---|
| Текст задания / упражнения | Чтобы я понял формат и сложность |
| Свой вариант ответа | Чтобы я мог указать на конкретные ошибки |
| Конкретный вопрос («в чём разница между X и Y?») | Чтобы я не уходил в общие объяснения |
| Указание уровня («HSK2 урок 5») | Чтобы я попадал в лексику учебника |
| Сколько слов нужно в ответе | Чтобы я не делал ответ слишком коротким или длинным |

## Часть 4. Чего я НЕ могу и как это компенсировать

| Ограничение | Как компенсировать |
|---|---|
| **Не слышу произношение** | Anki с озвучкой + Speaking-приложения (HelloChinese, Du Chinese, iTalki) + регулярные сессии с носителем |
| **Не проверю рукописный иероглиф** | Писать в Pleco Handwriting (он распознаёт) или в тетради + сверять с эталоном в учебнике |
| **Не знаю 100% свежих нюансов формата** | Уточнять у преподавателя Института Конфуция; сверяться с официальным сайтом chinesetest.cn |
| **Могу ошибиться в тонкостях узуса** | Сверять с примерами в HSK Standard Course + консультация с тьютором |
| **Не могу вести 100% устной практики** | HelloChinese, разговорные клубы, iTalki-тьютор |
| **Не могу эмулировать экзаменационную среду** | Mock-тесты на chinesetest.cn или hsk.academy |
| **Не знаю лично слушателя** | Спрашивать у ученика уровень, прогресс, конкретные трудности |

## Часть 5. Стратегия подготовки к HSK2

### 5.1. Таймлайн (примерный план на 3 месяца)

**Месяц 1: База**

| Неделя | Что делать со мной | Что делать с тьютором / самостоятельно |
|---|---|---|
| 1 | Получить список 300 слов HSK2, начать Anki-карточки | Закрепить тоны, базовые фонетические правила |
| 2 | Разобрать первые 5 грамматических тем (你好, 我, 是, 的, 有) | Прочитать первые 3 урока HSK Standard Course 2 |
| 3 | Сгенерировать 50 упражнений на пройденные темы | Активная практика произношения |
| 4 | Мини-тест по лексике и грамматике месяца 1 | Аудирование — слушать подкасты, смотреть видео |

**Месяц 2: Расширение**

| Неделя | Что делать со мной | Что делать с тьютором / самостоятельно |
|---|---|---|
| 5 | Разобрать средние темы (модальные глаголы, 了, счётные слова) | Прочитать уроки 4-8 HSK Standard Course 2 |
| 6 | Сгенерировать диалоги и тексты по пройденным темам | Ежедневно 30 мин — слушать китайскую речь |
| 7 | Разбор ошибок: ученик присылает свои письменные работы | Произносительная практика с тьютором |
| 8 | Пробный тест (полный вариант HSK2) | Разбор ошибок с тьютором |

**Месяц 3: Финиш**

| Неделя | Что делать со мной | Что делать с тьютором / самостоятельно |
|---|---|---|
| 9 | Разбор сложных тем (отрицания 不/没, текстовые связки) | Пробные тесты раз в 2-3 дня |
| 10 | Генерация «кейс-задач» — задания в формате экзамена | Ежедневно: 1 тренировочный вариант на время |
| 11 | Анализ ошибок по итогам пробных | Финальная консультация с тьютором |
| 12 | Финальный mock-тест, разбор, последние вопросы | Сдача экзамена |

### 5.2. Ежедневный режим

| Длительность | Что делать |
|---|---|
| **15 мин** | Anki — повторение карточек по лексике |
| **15 мин** | Прослушивание — подкаст, видео на китайском с субтитрами |
| **15 мин** | Упражнения со мной (генерация, проверка) |
| **15 мин** | Чтение текста из учебника + запись иероглифов |
| **2-3 раза в неделю** | Занятие с тьютором (1-1.5 часа) |

**Итого: 1 час в день + тьютор 2-3 раза в неделю.**

### 5.3. Что делать за неделю до экзамена

- Только пробные тесты на время
- Не учить нового — только повторять пройденное
- Проверить организационные моменты: паспорт, регистрация, адрес, время
- Выспаться
- Последний день — отдых

## Часть 6. Где моя помощь максимально эффективна

### 6.1. Топ-5 ситуаций, где я лучший помощник

1. **Объяснить грамматическую конструкцию** — дать правило, 15-20 примеров, ловушки
2. **Сгенерировать упражнения** — за 30 секунд 10-20 заданий на любую тему HSK2
3. **Разобрать ошибки в тексте ученика** — перевод, эссе, упражнение
4. **Составить диалог или текст** — на любую тему, в формате HSK2
5. **Систематизировать лексику** — карточки Anki, тематические группы

### 6.2. Топ-5 ситуаций, где тьютор Института Конфуция незаменим

1. **Произношение, интонация, тоны** — только живой звук и обратная связь
2. **Устная речь, разговорная практика** — мне не хватает естественности
3. **Актуальный формат экзамена** — уточнить, что именно в вашем центре тестирования
4. **Культурный контекст** — живые истории, реалии современного Китая
5. **Эмоциональная поддержка и мотивация** — человеческое отношение

### 6.3. Оптимальная модель «тьютор + я»

| За что отвечает тьютор Института Конфуция | За что отвечу я |
|---|---|
| Произношение, интонация, тоны | Систематическое объяснение грамматики |
| Живая разговорная практика | Генерация упражнений и тестов |
| Оценка устной речи | Разбор письменных работ |
| Культурный контекст «от первого лица» | Разбор ошибок и объяснение ловушек |
| Актуальный формат экзамена | Карточки Anki, списки лексики |
| Эмоциональная поддержка | Ответы на вопросы «на лету» |
| | Помощь между занятиями (24/7) |

## Часть 7. Как со мной работать (практические советы)

### 7.1. Что говорить в начале сессии

Чтобы я давал максимально релевантные ответы, скажите мне:

```
Я учу китайский в Институте Конфуция, готовлюсь к HSK2.
Сейчас изучаю урок N из HSK Standard Course 2.
Мой уровень: HSK1 (сдал/не сдавал).
Какие трудности: ... (произношение / лексика / грамматика / всё)
Дата экзамена: YYYY-MM-DD (если знаете)
Сколько недель до экзамена: N
```

### 7.2. Какие запросы дают лучший результат

**Хорошие запросы:**

- ✅ «Объясни разницу между 不 и 没 в китайском, с 10 примерами»
- ✅ «Дай мне 15 упражнений на счётные слова (量词)»
- ✅ «Сделай мне мини-тест по лексике HSK2 урок 5»
- ✅ «Разбери мой перевод этого предложения: 我昨天去了商店买两个苹果»
- ✅ «Составь диалог про покупки, 5 реплик, с пиньинь и переводом»
- ✅ «Сгенерируй мне CSV для Anki по теме Семья (10 карточек)»

**Не очень эффективные запросы:**

- ⚠️ «Выучи меня китайскому» — слишком общо
- ⚠️ «Как лучше учить?» — лучше с конкретным контекстом
- ⚠️ «Напиши эссе за меня» — не поможет на экзамене

### 7.3. Как проверить мой ответ

Если не уверены в моём ответе:
- Сверьте с учебником HSK Standard Course 2
- Спросите у тьютора Института Конфуция
- Найдите похожие примеры в Pleco / HelloChinese

## Часть 8. Ограничения и честность

### 8.1. Что я подтверждаю

- Могу помочь с HSK2 на уровне «хороший репетитор» для письменной части
- Могу разобрать грамматику, сгенерировать упражнения, проверить переводы
- Могу подготовить к логике экзамена
- Могу объяснить китайскую грамматику на русском
