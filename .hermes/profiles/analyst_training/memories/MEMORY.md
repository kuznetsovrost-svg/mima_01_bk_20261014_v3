Прежде чем изменять файлы профиля (.db, .yaml, .md), Rost ожидает: (1) бэкап с .bak-расширением, (2) точечные правки с верификацией через grep/select до и после, (3) проверка отсутствия побочных ссылок на изменяемое значение (slug, name, id) в других файлах профиля. Указывает на опечатки сам — помогать с их поиском автоматически.

SKILL review workflow: when a user pastes a candidate SKILL.md and asks "is this valid?" / "check before commit" — produce a structured report (BLOCKER / WARN / Substance / Typos), write it next to the source as `<stem>-rep01.txt`, and wait for explicit go-ahead before calling `skill_manage(action='create')` or `write_file` to a SKILL.md path. Pattern lives in user-local skill `skill-candidate-review` under software-development category; bundled `hermes-agent-skill-authoring` is read-only from background sessions.

При отправке файлов ему явно брать токен из /root/.hermes/.env (default profile), НЕ из /root/.hermes/profiles/analyst_training/.env. Активный профиль менять НЕ нужно. Правило: «с какого бота запрос → тому боту и ответ».
