# Excalidraw Grid Analyzer

Анализ Excalidraw файлов с таблицей навыков: парсинг структуры, извлечение сущностей, сопоставление с описаниями.

## Когда использовать

- Excalidraw файл содержит таблицу навыков (Frame "Таблица WxH")
- Нужно узнать, какие навыки описаны, какие имеют описание, а какие нет
- Нужно найти расхождения между именами в таблице и описаниях
- Нужно проверить покрытие (что у всех сущностей есть описания)
- Нужно извлечь описание конкретного навыка по номеру

## Структура Excalidraw файла

### Frame "Таблица WxH" (основная таблица)
- Имя Frame парсится regex: `^Таблица\s+(\d+)[xхХX](\d+)\s*$`
- `cell_width = W`, `cell_height = H`
- Внутри — клетки, каждая = группа из 3-х элементов:
  1. Прямоугольник (background)
  2. `##NNN` (текст с номером сущности)
  3. Наименование (текст БЕЗ `#` в начале)

### Frame "Описание" (или любой другой)
- Содержит описания, расположенные в **произвольном порядке**
- Группа описания = 4 элемента:
  1. Прямоугольник (background)
  2. `##NNN`
  3. `#Наименование` (начинается с `#`, не `##NNN`)
  4. Многострочный текст (само описание)

## Сопоставление (двойная проверка)

Для каждой сущности таблицы ищется описание, где **ОДНОВРЕМЕННО**:
1. `##NNN` совпадает
2. Имя (после снятия `#` в описании) совпадает с именем в таблице

Если одно не совпадает — это **РАСХОЖДЕНИЕ**.

## Использование

CLI запускается из каталога `scripts/` (там `grid_analyzer.py`):

```bash
cd /root/.hermes/skills/creative/excalidraw-grid-analyzer/scripts
python3 grid_analyzer.py <команда> [NNN] <файл.excalidraw>
```

### Команды

| Команда | Что делает |
|---|---|
| `summary` | Общая статистика: размер Frame, размер сетки, кол-во сущностей, покрытие |
| `list-skills` | Все сущности таблицы (NNN, позиция, имя) |
| `list-descriptions` | Все описания (NNN, имя, длина, превью текста) |
| `get-skill NNN` | Подробности о сущности NNN + связанное описание |
| `get-description NNN` | Только текст описания NNN (для передачи пользователю) |
| `find-orphan-descriptions` | Описания, у которых нет сущности в таблице |
| `find-missing-descriptions` | Сущности без описания |
| `find-name-mismatches` | NNN совпал, но имена разные |
| `coverage` | % покрытия |
| `match-skills` | Полный отчёт в JSON |
| `validate` | Все проверки + exit code (0=ok, 1=проблемы) |

### Примеры

```bash
# Общая статистика
python3 grid_analyzer.py summary my-skills.excalidraw

# Получить описание навыка #003
python3 grid_analyzer.py get-description 003 my-skills.excalidraw

# Найти сущности без описания
python3 grid_analyzer.py find-missing-descriptions my-skills.excalidraw

# Полная валидация (для CI/CD)
python3 grid_analyzer.py validate my-skills.excalidraw
```

## Структура модулей

- `grid_parser.py` — парсинг Frame имени, классификация текстов (NNN, имя, описание), разделение групп по положению относительно Frame
- `cell_extractor.py` — извлечение клеток (группы из 3-х элементов)
- `description_extractor.py` — извлечение описаний (группы из 4-х элементов)
- `skill_matcher.py` — сопоставление сущностей с описаниями по двойной проверке
- `grid_analyzer.py` — CLI

## Ограничения

- Имя Frame должно точно соответствовать regex `Таблица WxH` (с пробелом)
- `##NNN` распознаётся по regex `^#+\s*(\d+)\s*$`
- Имя в таблице НЕ должно начинаться с `#`
- Имя в описании ОБЯЗАНО начинаться с `#` (но не `##NNN`)
- Для описания выбирается самый длинный текст-кандидат в группе (не начинающийся с `#`)
