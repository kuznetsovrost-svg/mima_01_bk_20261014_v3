# Conventions for excalidraw-grid-analyzer

Подробное описание соглашений по разметке таблиц навыков в Excalidraw.

## 1. Frame "Таблица"

### 1.1 Имя

Имя Frame содержит размер клетки в пикселях.

**Обязательные форматы:**

| Формат | Пример | Что означает |
|---|---|---|
| `Таблица WxH` | "Таблица 500x300" | cell=500×300 |
| `grid=WxH` | "grid=500x300" | то же |
| `grid: WxH` | "grid: 500x300" | то же |
| `cell_w=W cell_h=H` | "cell_w=500 cell_h=300" | то же |

**Дополнительные параметры:**

```
"cell_w=500 cell_h=300 off_x=50 off_y=50"
```

Параметр `off_x` и `off_y` определяют отступ от верхнего левого угла Frame до первой клетки. По умолчанию = 50.

### 1.2 Размер Frame

`width` и `height` Frame задают **сколько клеток помещается**:

```
Frame width=1500, height=900
cell_width=500, cell_height=300
    -> cols = 1500 / 500 = 3
    -> rows = 900 / 300 = 3
```

Если Frame не поделён идеально (например 1450 / 500 = 2.9), берётся `round()` → 3.

### 1.3 Frame ID

`id` Frame используется в `frameId` элементов-навыков для привязки.

## 2. Группа навыка в клетке

Внутри каждой клетки — **ровно 3 элемента** с одинаковым `groupIds`:

### 2.1 Структура

```
{
  "elements": [
    { "id": "r-001", "type": "rectangle",
      "groupIds": ["skill-001"], "frameId": "frame-table",
      "x": 100, "y": 100, "width": 400, "height": 200 },
    { "id": "t-001", "type": "text",
      "groupIds": ["skill-001"], "frameId": "frame-table",
      "x": 130, "y": 130, "width": 60, "height": 30,
      "text": "##001" },
    { "id": "n-001", "type": "text",
      "groupIds": ["skill-001"], "frameId": "frame-table",
      "x": 200, "y": 180, "width": 250, "height": 30,
      "text": "Анализ требований" }
  ]
}
```

### 2.2 Правила

| Элемент | Тип | Содержание | Где |
|---|---|---|---|
| Прямоугольник | `rectangle` | пустой | внутри клетки |
| Номер | `text` | `##NNN` (NNN = число) | в углу прямоугольника |
| Имя | `text` | текст без `#` и без `##` | в центре |

### 2.3 Номер навыка

Формат: `##NNN` где NNN — целое число.

Допустимые варианты:
- `##1`, `##2`, ..., `##99`
- `##001`, `##002`, ..., `##999`
- `##0001`, `##0002`, ...

Номер **уникален** в пределах файла. Не может быть двух навыков с одинаковым номером.

## 3. Frame "Описание"

### 3.1 Имя

Имя Frame должно содержать слово **"описание"** (или **"description"**):

```
Frame name: "Описание"
Frame name: "Описание навыков"
Frame name: "Skill descriptions"
```

### 3.2 Структура группы

Группа описания — **ровно 4 элемента**:

```
{
  "id": "r-d001", "type": "rectangle",
  "groupIds": ["desc-001"], "frameId": "frame-desc" },
{ "id": "t-d001", "type": "text", "text": "##001",
  "groupIds": ["desc-001"], "frameId": "frame-desc" },
{ "id": "n-d001", "type": "text", "text": "#Анализ требований",
  "groupIds": ["desc-001"], "frameId": "frame-desc" },
{ "id": "desc-d001", "type": "text",
  "text": "Этап 1: сбор требований\nЭтап 2: анализ\nЭтап 3: ТЗ",
  "groupIds": ["desc-001"], "frameId": "frame-desc" }
```

### 3.3 Правила

| Элемент | Тип | Содержание | Отличие от таблицы |
|---|---|---|---|
| Прямоугольник | `rectangle` | пустой | — |
| Номер | `text` | `##NNN` | тот же номер что у навыка |
| Имя | `text` | начинается с `#` | **с префиксом** `#` |
| Описание | `text` | многострочный текст | длиннее 50 символов или `\n` |

## 4. Алгоритм парсинга

### 4.1 Поиск Frame таблицы

1. Проходим по всем `type=frame`
2. Ищем Frame с `is_table_frame(name) == True` (имя содержит "Таблица")
3. Извлекаем сетку через `parse_grid_from_frame_name(name)`

### 4.2 Поиск Frame описаний

1. Проходим по всем `type=frame`
2. Ищем Frame с `is_description_frame(name) == True` (имя содержит "Описание")

### 4.3 Вычисление размеров таблицы

```
num_cols = round(frame.width / cell_width)
num_rows = round(frame.height / cell_height)
```

### 4.4 Извлечение навыков

Для каждой клетки `(row, col)`:
1. Группируем все элементы по `groupIds`
2. Для каждой группы проверяем: есть ли элемент в клетке?
3. Если да — парсим как `##NNN + name` + rectangle
4. Возвращаем список

### 4.5 Связь с описанием

Поиск по номеру `##NNN`:
- В таблице — найти клетку с этим номером
- В описании — найти группу с тем же номером

## 5. Что НЕ поддерживается

- ❌ Стрелки между навыками
- ❌ Цветовое кодирование навыков
- ❌ Иконки/эмодзи в группах
- ❌ Изображения как навыки
- ❌ Несколько навыков в одной клетке (одна группа — один навык)
- ❌ Заголовки строк/колонок (нет в текущей спецификации)
- ❌ Многоуровневая иерархия навыков
