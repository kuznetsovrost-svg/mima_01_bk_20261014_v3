# Примеры IDEF0 в Excalidraw

## Пример 1: Простая A-0 диаграмма

### Структура

```
┌─ Frame: A-0 ──────────────────────────────────┐
│                                                │
│      ┌─────────────────────────┐              │
│  →──│                         │──→            │
│  →──│  Обработка заявок      │──→            │
│  ──→│        A-0.1            │──→            │
│  →──│                         │──→            │
│      └─────────────────────────┘              │
│     ↑          ↓                                │
│     C          M                                │
└────────────────────────────────────────────────┘
```

## Пример 2: A1 — декомпозиция блока A0-2

### Структура

```
┌─ Frame: A1 Обработка (parent: A0-2) ─────────┐
│                                                │
│  →I1─→[Блок 1. Ввод]─O1─→                      │
│        ↓                ↓                       │
│      [Блок 2. Проверка]─O2─→                    │
│        ↓                                       │
│      [Блок 3. Утверждение]─O3─→                │
│                                                │
└────────────────────────────────────────────────┘
```

### ICOM блоков

Блок 1 (Ввод):
- На основании: C1 (правила)
- Получает: I1 (заявка)
- Выдаёт: O1 (заявка проверенная)

Блок 2 (Проверка):
- На основании: C1 (правила)
- Получает: O1 (от блока 1)
- Выдаёт: O2 (результат проверки)

Блок 3 (Утверждение):
- На основании: C1 (правила)
- Получает: O2 (от блока 2)
- Выдаёт: O3 (финальное решение)

## Пример 3: Туннель

### Стрелка с туннелем

```
Блок A0-2 на A0:    ←( C1 Стандарты )
                       ↑ скобки вокруг точки привязки

Диаграмма A1:       ←( C1 Стандарты )
                       (проходит сквозь — попадает в ICOM листа A1)
```

В тексте стрелки: `"( C1 Стандарты"`

## Пример 4: Каталог объектов

### Для A2 диаграммы

```
| Имя                | Источник    | Получатель  | Тип |
| Заявка клиента     | Граница     | Блок 1      | I   |
| Правила работы     | Граница     | Блок 1,2,3  | C   |
| Заявка проверенная | Блок 1      | Блок 2      | -   |
| Отчёт              | Блок 2      | Граница     | O   |
| Менеджер           | Граница     | Блок 1,2    | M   |
| База данных        | Граница     | Блок 2,3    | M   |
```

## Использование скилла

```bash
# Валидация
python3 validator.py validate --file diagram.excalidraw

# Генерация каталога
python3 validator.py generate-catalogue --file diagram.excalidraw --frame "A2"

# Проверка ICOM consistency
python3 validator.py check-icom --file diagram.excalidraw --parent "block-A0-2"

# Генерация описаний
python3 validator.py generate-description --file diagram.excalidraw
```
