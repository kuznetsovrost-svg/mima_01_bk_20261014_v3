# Соглашения по разметке IDEF0 в Excalidraw

## Структура блока

Блок IDEF0 = группа из 3 элементов:

```
block-<N>    прямоугольник
func-<N>     текст имени (центр)
num-<N>      текст номера (нижний левый угол)
group-<N>    имя группы (общий groupIds)
```

### Пример блока "Разработка чертежей" (A1.2)

```json
{
  "elements": [
    {
      "id": "block-A1-2",
      "type": "rectangle",
      "x": 100, "y": 100,
      "width": 200, "height": 100,
      "groupIds": ["group-A1-2"]
    },
    {
      "id": "func-A1-2",
      "type": "text",
      "text": "Разработка чертежей",
      "x": 120, "y": 140,
      "width": 160, "height": 20,
      "textAlign": "center",
      "groupIds": ["group-A1-2"]
    },
    {
      "id": "num-A1-2",
      "type": "text",
      "text": "A1.2",
      "x": 105, "y": 175,
      "width": 30, "height": 15,
      "textAlign": "left",
      "groupIds": ["group-A1-2"]
    }
  ]
}
```

## Уровни (Frame)

Имя Frame: `"A<n> <Описание> (parent: A<m>-<код>)"`

### Примеры

- `"A-0 Контекст"` — корневая диаграмма
- `"A0 (parent: A-0)"` — декомпозиция A-0
- `"A1 Обработка заявки (parent: A0-2)"` — декомпозиция блока 2 из A0

## Стрелки ICOM

### Обычная

```json
{
  "id": "arrow-I1",
  "type": "arrow",
  "text": "I1 Заявка клиента",
  "startBinding": {"elementId": "..."},
  "endBinding": {"elementId": "block-A1-1"}
}
```

### Туннелированная

```json
{
  "id": "arrow-C1-tunnel",
  "type": "arrow",
  "text": "( C1 Стандарты",
  ...
}
```

Скобка в начале = туннель на конце стрелки.
Скобка в конце = туннель на начале стрелки.
С обеих сторон = двойной туннель.

## Каталог объектов

Frame внутри диаграммы: `"Arrow Catalogue A2"`

Содержит таблицу с полями: Имя | Источник | Получатель | Тип.

## Размеры (рекомендации)

- Блок: 200x100 px
- Текст функции: 16-20 px
- Текст номера: 10-12 px
- Frame: на 20-50 px больше содержимого
- Таблица каталога: 400x300 px
