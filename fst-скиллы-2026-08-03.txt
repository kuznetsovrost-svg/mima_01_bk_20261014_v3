### Базовые (без категории) (core) — 5 шт.

• core/computer-use
  Назначение: Drive the user's desktop in the background — clicking, typing, scrolling, dragging, and switching virtual desktops / Spaces. Cross-platform: macOS, Windows, Linux. Works with any tool-capable model. Load this skill whenever the computer_use tool is available.
• core/dogfood
  Назначение: Exploratory QA of web apps: find bugs, evidence, reports.
• core/hermes-gateway-troubleshooting
  Назначение: Use when a Hermes messaging gateway (Telegram, Discord, Slack, etc.) is misbehaving — startup fails, messages don't reach the bot, delivery is silent, or the user reports 'the bot doesn't respond'. Covers the diagnostic recipe, the .env-vs-config.yaml source-of-truth trap, and per-platform log signatures. Load for any 'why isn't my bot working' task.
• core/mcp-server-probing
  Назначение: Use when an MCP tool returns an unexpected error, the documented parameters don't work, you need to discover what a server actually exposes, or the wired-up tools misbehave. Covers direct SSE probing via curl, reading Pydantic validation errors to discover real parameter names, the mcp-session-id header dance, and the verify-after-write pattern. Loads when any mcp__<server>__* tool fails or when you need to understand a server's true schema vs its advertised one.
• core/yuanbao
  Назначение: Yuanbao (元宝) groups: @mention users, query info/members.
