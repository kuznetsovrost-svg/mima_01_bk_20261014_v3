# Компонент-открывашка в Figma: collapsed/expanded варианты

## Главное правило

**Один Component с Variants `state=collapsed|expanded`**, не два отдельных Frame. Только так можно:
- Связать строку и таблицу через Toggle Action (auto-switch при клике в prototype)
- Использовать Auto Layout чтобы при добавлении строк таблица расширялась
- Получить единый Style через Variants Property

## Структура компонента

```
📦 cmp.collapsible-row (Component)
├── variant=collapsed (default)
│   └── Frame "row" (Auto Layout horizontal, gap: 12px, padding: 12×16)
│       ├── icon.chevron-right (16×16)
│       ├── Text "title" (Body/Default, weight 500) — "{rows.length} замечаний"
│       └── Spacer (fill)
│
└── variant=expanded
    └── Frame "row" (Auto Layout vertical, gap: 0)
        ├── Frame "header" (Auto Layout horizontal, gap: 12px, padding: 12×16)
        │   ├── icon.chevron-down (16×16)
        │   ├── Text "title"
        │   └── Spacer (fill)
        └── Frame "body" (Auto Layout vertical, gap: 0, padding: 0×16 12×16)
            └── Table (см. Таблица-в-FIGMA.md)
```

## Детальная разметка

### Frame `row` (Auto Layout)

| Свойство | collapsed | expanded |
|---|---|---|
| Direction | Horizontal | Vertical |
| Gap | 12px | 0px |
| Padding | 12×16 | 0 (header/body свои) |
| Fill | Background/Card | Background/Card |
| Stroke | Border/Default 1px | Border/Default 1px |
| Corner Radius | radius/Lg (8px) | radius/Lg (8px) |
| Width | Fill container (100%) | Fill container (100%) |

### Frame `header` (только для expanded)

| Свойство | Значение |
|---|---|
| Direction | Horizontal |
| Gap | 12px |
| Padding | 12×16 |
| Stroke bottom | Border/Default 1px |
| Fill | Background/Section (#F9FAFB) |

### Frame `body` (только для expanded)

| Свойство | Значение |
|---|---|
| Direction | Vertical |
| Padding | 0 top, 16 sides, 12 bottom |
| Fill | Background/Card |

## Иконки chevron

| Имя слоя | collapsed | expanded |
|---|---|---|
| `icon.chevron-right` | ➔ (16×16, TextHeadingSubtle) | — |
| `icon.chevron-down` | — | ⬔ (16×16, TextHeadingSubtle) |

**Совет:** используй иконку из библиотеки Feather/Lucide, либо Unicode-символ в Text-слое (→ collapsed, ↓ expanded). Unicode — проще для экспорта.

## Text слой `title`

| Свойство | collapsed | expanded |
|---|---|---|
| Содержимое | `{rows.length} {noun.form}` | то же |
| Style | Body/Default, weight 500 | то же |
| Color | Text/HeadingPrimary | то же |
| Alignment | Left | Left |

**Плейсхолдер формат для collapsed:**
```
{rows.length} замечаний    ← для 0
{rows.length} замечание    ← для 1
{rows.length} замечания    ← для 2-4
{rows.length} замечаний    ← для 5+
```

**Упрощённый вариант:** всегда `{rows.length} записей` (как в GitHub Issues).

## Таблица внутри body

Согласно Таблица-в-FIGMA.md:
- `sec.table` → `tbl.thead` (горизонтально) + `tbl.tbody` (вертикально, Auto Layout)
- `tbl.tbody` содержит **одну строку-шаблон** `tr.template` (горизонтально)
- Loop в HTML: `for row in rows: <tr>...</tr>`

## Component Property (Variants)

В панели Variants:
```
Property: state
  Values: collapsed, expanded
```

**Правильно:** один Component, два варианта (collapsed как default).
**Неправильно:** два отдельных Component `RowCollapsed` и `RowExpanded`.

## Auto Layout constraints (критично)

| Правило | Почему |
|---|---|
| `row` (expanded) — **vertical Auto Layout** | Таблица под header'ом, а не рядом |
| `header` (expanded) — **horizontal Auto Layout** | Иконка + текст в одну строку |
| `body` (expanded) — **vertical Auto Layout** | Таблица одна, без горизонтальных вложений |
| `tr.template` — **horizontal Auto Layout** | Ячейки в строку |
| `tbl.tbody` — **vertical Auto Layout** | Строки друг под другом |
| `Width` всех Frame'ов = **Fill container** | Растягивается по родителю |

## Прототип: Toggle при клике

1. На компоненте `cmp.collapsible-row` открой **Prototype** панель
2. На Frame `header` (expanded) добавь **On click → Change to → state=expanded → collapsed**
3. На Frame `header` (collapsed) добавь **On click → Change to → state=collapsed → expanded**

**Лучше:** сделать отдельный **Instance** `header.interaction` с теми же bounds, поставить его сверху и привязать On click. Так не ломается layout.

## Что попадёт в HTML (после экспорта)

```html
<details class="collapsible">
  <summary class="collapsible-header">
    <span class="icon-chevron">→</span>
    <span class="collapsible-title">3 замечания</span>
  </summary>
  <div class="collapsible-body">
    <table class="remarks-table">
      <thead>
        <tr>
          <th>№</th>
          <th>Статус</th>
          <th>Код</th>
          <th>Название</th>
          <th>План</th>
          <th>Прогноз</th>
          <th>Факт</th>
          <th>Исполнитель</th>
        </tr>
      </thead>
      <tbody>
        <tr>
          <td>1</td>
          <td><span class="badge badge--critical">Критическое</span></td>
          <td>104-721</td>
          <td>...</td>
          ...
        </tr>
      </tbody>
    </table>
  </div>
</details>
```

**Без JavaScript** — `<details>`/`<summary>` нативно поддерживает toggle во всех браузерах.

## Генерация в HTML-шаблоне (Jinja2)

```jinja
<details class="collapsible" {% if section.default_open %}open{% endif %}>
  <summary class="collapsible-header">
    <span class="icon-chevron" aria-hidden="true">→</span>
    <span class="collapsible-title">
      {{ section.rows|length }} {{ section.noun or 'записей' }}
    </span>
  </summary>
  <div class="collapsible-body">
    {% include 'partials/table.html' with context %}
  </div>
</details>
```

## CSS для компонента

```css
.collapsible {
  background: var(--bg-card);
  border: 1px solid var(--border-default);
  border-radius: var(--radius-lg);
  overflow: hidden;
}

.collapsible-header {
  display: flex;
  align-items: center;
  gap: var(--spacing-3);  /* 12px */
  padding: var(--spacing-3) var(--spacing-4);  /* 12px 16px */
  cursor: pointer;
  user-select: none;
  background: var(--bg-section);
  border-bottom: 1px solid var(--border-default);
}

.collapsible[open] > .collapsible-header {
  background: var(--bg-section);
}

.collapsible-header:hover {
  background: var(--bg-subtle);
}

.icon-chevron {
  display: inline-block;
  transition: transform 0.2s ease;
  color: var(--text-heading-subtle);
}

.collapsible[open] > .collapsible-header .icon-chevron {
  transform: rotate(90deg);
}

.collapsible-title {
  font: var(--body-default);  /* Inter 16px */
  font-weight: 500;
  color: var(--text-heading-primary);
}

.collapsible-body {
  padding: var(--spacing-4);  /* 16px */
}

/* Таблица внутри */
.collapsible-body .remarks-table {
  width: 100%;
  border-collapse: collapse;
}

.collapsible-body .remarks-table th,
.collapsible-body .remarks-table td {
  padding: var(--spacing-3);
  text-align: left;
  border-bottom: 1px solid var(--border-muted);
}
```

## Светлая и тёмная тема

Всё работает автоматически, потому что все цвета — токены:
- `--bg-card`, `--bg-section`, `--bg-subtle`
- `--border-default`, `--border-muted`
- `--text-heading-primary`, `--text-heading-subtle`
- `--radius-lg`, `--spacing-*`

При переключении темы (через Tokens Studio или `data-theme="dark"`) компонент меняет цвета.

## Адаптивность (мобильный breakpoint)

На <768px:
```css
.collapsible-body {
  padding: var(--spacing-3);  /* меньше отступы */
  overflow-x: auto;  /* горизонтальный скролл для таблицы */
}

.collapsible-body .remarks-table {
  min-width: 600px;  /* минимум чтобы не сжималась */
}
```

## Доступность (a11y)

| Что | Как |
|---|---|
| `<details>` + `<summary>` | Нативно поддерживает клавиатуру (Enter/Space) |
| `aria-expanded` | Браузер ставит автоматически |
| `aria-controls` | Опционально: `<summary aria-controls="remarks-body">` |
| Фокус | `<summary>` получает focus-ring автоматически |
| Скринридер | Читает "Список, 3 замечания, кнопка свёрнуто/развёрнуто" |

## Чек-лист при создании в Figma

- [ ] Component называется `cmp.collapsible-row`
- [ ] Variants: `state=collapsed` (default), `state=expanded`
- [ ] `row` Frame — Auto Layout (vertical в expanded, horizontal в collapsed)
- [ ] `header` (только в expanded) — отдельный Frame с bottom border
- [ ] Иконка chevron: right в collapsed, down в expanded
- [ ] Text `title` содержит плейсхолдер `{rows.length} записей`
- [ ] Таблица внутри `body` (expanded) — одна строка-шаблон + `{rows[N].field}`
- [ ] Width всех Frame'ов = Fill container
- [ ] Prototype: On click → Change to → alternate state
- [ ] Auto Layout включён везде
- [ ] Цвета через Color Styles (Status/Critical/Bg и т.д.)

## Альтернативы (когда НЕ подходит)

| Альтернатива | Когда использовать |
|---|---|
| **Два отдельных Frame** (не Component) | Если toggle не нужен (статичная раскрытая таблица) |
| **Modal dialog** | Если таблица очень большая и нужно затемнение |
| **Tabs** | Если вариантов больше 2 (например, "Все/Активные/Закрытые") |
| **Accordion group** | Если на странице несколько связанных секций с одним открытым |
| **Side panel** | Если таблица — это фильтры/настройки |

## Шпаргалка одной строкой

> Один Component `cmp.collapsible-row`, Variants `state=collapsed|expanded`, Auto Layout vertical в expanded, header отдельным Frame с bottom border, chevron иконка меняется, title с плейсхолдером, в body — таблица с `{rows[N].field}`, prototype с Toggle, в HTML — `<details>` без JS.
